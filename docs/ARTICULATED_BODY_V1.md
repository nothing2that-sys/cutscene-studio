# 작화 인체 v1

이 문서는 현재 제품 동작을 설명합니다. 독립 시각 검수·자산 바인딩·통합 종결은 진행 중이며 최종 완료 판정이 아닙니다.

2026-11-04 중단 원인, 구현 범위와 미완 검증은 [현재 작업 상태](ARTICULATED_BODY_V1_STATUS.md)에 정리했습니다.

## 실제 사용

메인 편집기에서 인물을 추가하고 관절/구도를 편집합니다. **앵글 고정 · 선화**는 현재 Perspective 카메라의 장면 전체를 가림과 함께 고정합니다. 드래그·휠 팬/줌은 캐시 화면 변환이고 개별 인물/소품의 위치·자세·가림·표시 또는 카메라 변경은 새 투영입니다. 작업/촬영 카메라와 저장·재열기·Undo/Redo를 지원합니다.

오른쪽 **공통 인체 · 추정 자세**의 두 버튼은 선택 인물에 새 자세·발 지지·위치 및 작업 카메라를 적용합니다. 원본은 자연 발 지지를 택한 대안 추정이고 P015는 뒤쪽 다리 추정을 포함한 공통 몸체 교차 자세입니다. 정확한 유일 복원으로 부르지 않습니다. 실제 사용자 액션과 검사 경로 모두 `body-v1-inferred-natural-sole-v1:original` / `body-v1-inferred-natural-hand-hip-v2:p015` 입력을 명시적으로 선택합니다.

기본 8등신 공통 몸체에서 키를 조절합니다. 별도 원본마다 전용 체형을 만들지 않습니다. 기존의 다른 체형/리그 파일은 legacy 표시로 유지하거나 지원하지 않는 조합을 명시적으로 거절합니다.

## 저장과 전달

`bodyAsset`은 `{id:"body-v1-default",version:1,rigVersion:"body-v1"}`를 유지합니다. 관절 기준축의 실제 변경은 `bodyV1Pose.basePose.restRevision=2`와 `driverRestRevision=2`로 구분합니다. revision 없는 구 v1 명시 quaternion과 driver residual은 구 pose를 먼저 평가한 뒤 새 rest 좌표로 변환하여 세계 자세를 보존합니다. 저장된 `preset` 이름으로 자세를 재생성하지 않습니다. 지원하지 않는 rest/driver revision은 장면 변경 전에 거절합니다.

`bodyAsset.version`은 저장 형식과 리그 계열을 나타냅니다. 표시 외피의 판본은 해당 앱 빌드의 자산·소스 해시와 독립 바인딩 보고서의 실제 중립 버퍼로 고정합니다. 구 저장 파일은 기존 관절의 세계 위치·방향을 현재 공통 외피로 재현하며, 손발 단순화·접힘 압축·관절 표면 분할 같은 형상 변경은 별도로 검증합니다.

새 P015 입력은 손목의 세계 방향과 실제 손가락 굽힘 20°/15°를 명시하며 공통 외피를 유지합니다. 기존 P015 v1 파일은 저장된 quaternion을 보존합니다. 새 source 자세도 explicit quaternion/driver residual을 저장하며 원래 request revision과 추정 의미를 provenance로 보존합니다. 로드시 provenance로 자세를 덮어쓰지 않습니다. 손발은 닫힌 단순 외피로 표시하고 기존 digit joint/curl 데이터는 보존합니다. 손바닥/발바닥의 실제 삼각형 기준점을 유지하며 세부 묘사는 인물 설명으로 전달합니다.

## 구현과 검증 경계

어깨의 고정 rest frame은 중립 벌림과 실제 팔꿈치 굽힘 평면을 구분합니다. 팔꿈치·무릎의 실제 CPU 외피는 고정 관절각을 바꾸지 않는 안쪽 접힘 압축을 사용합니다. 연결 cap과 부모의 닫힌 외피, 실제 triangle 표면 anchor가 등록됩니다. 접촉 보호는 단일 관절 입력에서 실제 침투 표본을 바탕으로 편집한 축만 후퇴시키고 요청각·적용각·이유를 기록합니다. 저장 자세와 프리셋은 다른 축을 자동 탐색하지 않으며, 중간 회전 구간은 끝자세와 구분하여 보고합니다. 이 진단은 독립 삼각형 검사를 대체하지 않습니다. 구조선은 실제 표시 삼각형에 bind하며 앞 물체 뒤의 선은 현재 카메라로 가립니다.

메인 표시 메시와 canonical study rig 사이에는 명시적인 균등 metre 변환이 있습니다. 모든 public pose mutator는 canonical CPU 업데이트 후 실제 표시 좌표로 돌아옵니다. standalone 전신 화면도 실제 metre display parent와 Perspective 카메라를 사용합니다. 발목 목표, 발 방향과 바닥은 채택한 원 입력을 검사하며 형상 변경 뒤 minY로 목표를 자동 보정하지 않습니다.

로컬 비교 원본 PNG는 보존하지만 빌드 산출물에서는 원본 내용 SHA256 대조로 제외합니다. 메인 인체·자세·저장·전달은 참고 PNG나 별도 참고 서버에 의존하지 않습니다.

최종 수치/실패·제한은 `validation/body-v1-M4-20261103/`의 실행 원문과 독립 검증 보고서로 구분합니다. 검사 준비나 자체 기능 검사만으로 SHAPE/POSE/CONTACT/LINE/EDITOR/DATA/PERF 전체 통과를 주장하지 않습니다.
