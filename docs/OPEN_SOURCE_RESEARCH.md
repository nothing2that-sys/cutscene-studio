# 소설 기반 3D 컷신 도구의 오픈소스 조사

2026년 11월 1일 기준으로 가장 빠른 출발점은 **pose-toolkit을 확장하는 로컬 브라우저 편집기**입니다. 공간과 촬영에는 Three.js를 유지하고, 소설의 장면 해석·컷 선정·연출 의도를 JSON으로 받는 부분을 추가합니다. 기존 컷신 스킬의 판단을 재사용하면서 포즈 검색과 중간 이미지 생성의 반복을 줄이는 방향입니다.

## 기반 선택

pose-toolkit은 이 작업의 가장 소모적인 중간 단계인 마네킹·관절·IK·포즈 저장·캡처를 이미 갖췄습니다. 추가할 작업이 소설용 장면 포맷, 공간·조명, 촬영 구도 관리에 집중됩니다. 초기 기반으로 채택한 커밋은 `5ad2d16ae107c8e5ee3304fd30bbadb7ed213e33`입니다.

A3D를 그대로 확장하면 생성 서비스·자산·타임라인·Electron 구조도 함께 다뤄야 합니다. 이번에는 로컬 편집·캡처에 필요한 부분에 집중하고 색/깊이 전달이라는 설계 아이디어를 차용합니다. OpenPose 출력과 ComfyUI 연결은 독립 어댑터로 추가할 수 있습니다.

Blender는 풍부한 모델링·리깅·렌더링이 필요해질 때 유용한 확장 경로입니다. 현재 목표인 소설 기반 초안의 빠른 수정에는 도구의 학습량과 설치 범위가 늘어납니다. 먼저 단순 마네킹과 공간 블록으로 구도 작업을 완성하고, 나중에 장면 교환을 지원하는 순서가 적절합니다.

## 실제 소스에서 드러난 개선점

pose-toolkit의 원래 저장은 카메라 위치·회전과 마네킹 자세 중심입니다. 컷신 작업에는 카메라 목표점·화각, 공간·조명, 소품, 컷 목록이 함께 필요합니다. 저장과 되돌리기의 범위를 여기에 맞춰 확장했습니다. 정밀 저장에는 자세 데이터뿐 아니라 실제 관절의 로컬 위치·회전·크기도 포함합니다.

Mannequin.js는 인스턴스 생성 시 공유 장면에 자동으로 인체를 추가합니다. LLM 배치를 계산하기 위해 임시 인체를 만들 때 이를 장면에서 제거하지 않으면 중복 인체가 남습니다. 장면 어댑터에서는 임시 인체를 바로 분리합니다. 원래 지면 높이와 프로젝트의 미터 단위를 맞추기 위해 발의 최저점을 계산해 바닥 또는 지정된 지지 높이에 배치합니다.

캡처는 편집 화면의 스크린샷보다 저장한 촬영 카메라로 별도 렌더링하는 방식이 적합합니다. 작업 화면을 움직여도 선택한 컷의 프레이밍은 유지되며, 화면비와 출력 해상도를 직접 지정할 수 있습니다. 이때 이동 핸들·그리드·축·선택 강조를 제거해야 작화 참조로 쓰기 좋습니다.

깊이 영상은 컬러와 같은 카메라·화면비·크기로 뽑아야 합니다. 이번 구현은 카메라 좌표의 선형 Z 깊이를 가까울수록 밝게 출력하고 near/far 값을 전달 묶음에 기록합니다. 생성기마다 요구하는 깊이 정규화·반전·범위가 다르므로 어댑터에서 맞춥니다. 현재 출력이 모든 ControlNet 모델의 입력 요구를 자동 충족한다고 보지 않습니다.

## 차별화할 고도화

첫째는 **관계로 지정하는 배치**입니다. LLM이 모든 관절의 숫자를 직접 작성하기보다 “인물 A가 의자 B에 앉고 오른손은 탁자 C에 닿는다”처럼 관계를 주고, 편집기가 지지면과 목표점을 계산하도록 합니다. 실제 수치와 사용자의 수정은 그대로 저장합니다.

둘째는 **사용자 수정의 보호**입니다. “조명만 다시 추천”할 때 사용자가 조정한 카메라와 포즈가 바뀌면 반복 작업이 돌아옵니다. ID·수정 경로·잠금 범위를 두고 LLM은 바뀔 부분만 제안하게 합니다. 제안은 미리보기 후 장면의 한 번의 실행 취소 단위로 적용합니다.

셋째는 **컷 사이의 연속성**입니다. 장소·인물·소품 ID를 공유하고 컷별 동작 상태를 저장합니다. 화면 좌우, 시선, 물건을 쥔 손, 지지점, 주광 방향의 불일치를 편집기에서 표시합니다. 작품마다 다른 컷 수나 스타일을 고정 템플릿으로 강제하지 않습니다.

넷째는 **확인 가능한 전달물**입니다. 컬러·깊이·포즈 이미지와 실제 장면 상태, 촬영 카메라, 인물 ID, 연출 의도를 함께 내보냅니다. 최초 LLM의 제안과 최종 사용자 수정 상태를 구분하며, 외형 정본 이미지는 자세·조명 참조와 역할을 나눕니다.

## 수집과 재사용 범위

조사 자료는 공개 저장소의 README·선택 소스·라이선스·변경 식별자입니다. 실제 재사용은 pose-toolkit과 그 의존성에 한정했고 라이선스를 보존했습니다. 포즈 갤러리와 3D 모델 라이브러리를 일괄 복제하지 않았습니다. 향후 모델·포즈 자산은 각 파일의 이용 조건과 원본 출처를 기록해 사용합니다.
