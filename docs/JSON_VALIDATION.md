# JSON 검사와 수정 요청 전달

장면 입력은 문법·지원 필드·자료형·단위·수치 범위·관절·기본 포즈·소품·중복 ID를 검사해 오류를 모아 표시합니다. 오류가 있으면 해당 JSON을 적용하지 않습니다. 정밀 프로젝트도 인물·소품 변환, 자세 데이터, 카메라, 스튜디오 상태를 검사한 뒤 복원합니다.

방 밖 배치, 바닥 아래 높이, 서 있는 인물이 방 높이를 넘는 경우, 표시된 벽 뒤의 카메라, 기본 방·조명 사용은 경고로 구분합니다. 경고는 의도적인 연출일 수 있어 적용을 허용합니다. 실제 인체 접촉·해부학·시선·가림·화면 구성은 이 수치 검사에 포함하지 않습니다.

검사만은 현재 장면을 바꾸지 않습니다. LLM 수정 요청 복사는 원본 JSON 문자열과 오류·경고·필드 경로·수정 지시를 함께 복사합니다. 보고서 저장은 같은 근거를 JSON 파일로 저장합니다. 클립보드 접근이 막히면 사용자가 선택해 복사할 텍스트를 표시합니다. 수정된 입력을 재검사하면 이전 검사 결과가 교체됩니다. 다른 버튼을 눌러 상태 안내가 바뀌어도 최근 검사 보고서는 남습니다.

전용 스킬은 reportVersion=1인 오류 보고서와 originalJSON을 인식하고 원본을 기준으로 수정합니다. 정밀 프로젝트를 최초 장면 제안으로 다시 만들지 않습니다. 경고를 모두 없애려고 연출을 무조건 변경하지 않습니다.

검증 명령: node --test scripts/scene-format.test.mjs scripts/scene-feedback.test.mjs

브라우저 검증: node scripts/validation-ui-check.mjs

검증 결과와 오류 화면: validation/json-feedback/browser-report.json, validation/json-feedback/error-ui.png
