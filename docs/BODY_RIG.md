# 인물 체형과 관절 제약

인물별 키 50~300cm와 등신 3~12를 설정합니다. 등신은 중립 기립 키를 머리의 세로 높이로 나눈 값입니다. 머리 크기와 전체 균일 스케일로 목표 비율과 키를 맞추며 몸통·팔다리의 기존 상대 길이 배분은 유지합니다. 굽힌 포즈의 화면 높이로 키를 다시 계산하지 않습니다.

포즈 변경은 로컬 관절 회전과 제약 IK입니다. 뼈 오프셋·스케일·모델 스케일은 boneLayout으로 고정합니다. 팔꿈치·무릎은 0~150도 힌지이며 다른 주요 관절은 설정된 각도 범위를 따릅니다. 목표가 도달 범위를 벗어나면 가능한 지점까지만 이동합니다. 여러 축의 회전 범위는 편집기의 단순 제한이며 신체 충돌·접촉·물리 균형을 자동 판정하지 않습니다.

저장·실행 취소·전달 묶음·단일 인물 내보내기에 bodyProfile과 boneLayout을 포함합니다. 로컬 뼈 위치나 스케일이 고정값과 달라진 정밀 프로젝트는 오류로 차단합니다. 구형 프로젝트는 기존 형태를 유지한 채 조작 시 현재 길이를 고정합니다.

검증: scripts/body-rig-check.mjs. 180cm의 5·8·9.5등신과 140cm의 5등신을 실제 지오메트리에서 측정했습니다. 80개 무작위 포즈에서 주요 관절 제한과 뼈 길이 보존, 먼 IK 목표의 도달 범위 제한, 인물별 설정 저장·재열기와 늘어난 뼈 데이터 거부를 확인했습니다. 근거는 validation/body-rig/report.json과 editor.png입니다.
