# 인체 외형 재설계 계획

2026-11-03. 기준: 사용자가 제공한 `9884.png`와 현재 `a9be299` 실제 렌더 비교.

## 현재 판정

**외형 요구 미충족.** 관절 분리·볼륨 유지·편집 기능 검증은 통과했지만, 사용자가 원하는 인체 형태와 닮았는지는 통과하지 못했다. 이전 테스트 통과를 외형 완성의 근거로 사용하지 않는다.

목표는 예제처럼 인체를 읽을 수 있는 작화용 입체 모형이다. 단색 표면, 방향을 읽는 보조선, 분리된 관절은 표현 수단이고, 우선순위는 전체 실루엣과 부위 사이의 연결 형태다.

## 제작 방식 변경

관절별 분리 구조는 유지할 수 있지만, 단순 단면 보간과 타원체 수치 조절을 최종 조형 방법으로 쓰지 않는다. 현재 `segmented-body.js`는 기능 실험 결과로 남기고, 새로운 외형은 별도 시제품으로 만든다.

기준 체형 하나를 **편집 가능한 저해상도 베이스 메시**로 조형한다. 흉곽·골반·어깨·팔다리의 앞/옆/뒤 단면과 주요 돌출점을 각각 조절할 수 있게 만든다. 가슴·어깨 등은 독립 구를 덧붙이는 형태에서 벗어나 넓은 부착부를 가진 표면으로 만든다. Blender 등 사용 가능한 메시 편집 도구를 먼저 확인하고, 도구가 없다면 제어점·단면을 명시적으로 편집하는 제작 경로를 정한다. 자동 생성만으로 원본 수준의 조형이 보장된다고 약속하지 않는다.

예제의 원형 관절은 그대로 드러내도 된다. 다만 이음부 위치·회전 여유·관절 덮개를 부위 외곽과 함께 설계해야 한다. 분리만 하면 닮아진다는 가정을 폐기한다.

## 단계와 통과 기준

1. **비교 조건 고정**
   - 원본 이미지와 같은 화면 방향·프레이밍·한팔 머리 위/다른 손 허리 포즈를 구성한다.
   - 머리 꼭대기·턱·어깨·팔꿈치·손목·골반·무릎·발목의 화면상 위치를 기록한다. 원본에서 가려진 관절은 추정으로 표시한다.
   - 실제 모형 캡처를 원본 옆에 배치하고 반투명 겹침도 만든다. 관절 위치와 외곽 오차를 분리해 본다.
   - 원본은 한 장의 그림이므로 숨은 면과 카메라 정보는 확정할 수 없다. 가려진 면은 별도 설계 가정으로 남긴다.
2. **외형 시제품 제작 — 앱 통합 전**
   - 우선 여성형 8등신 하나만 만든다. 머리·몸통·어깨·골반·팔다리를 조형한 뒤 손발을 맞춘다.
   - 회색 무광, 검은 실루엣, 선화의 세 표현으로 확인한다. 음영이나 보조선으로 형태 문제를 가리지 않는다.
   - 같은 포즈의 원본 대조와 중립 자세의 정면·측면·후면·사선 캡처를 제출한다.
   - 어깨 흐름, 가슴 부착부, 허리/골반, 허벅지/종아리 네 항목이 명확히 개선되기 전에는 앱 기본 외형을 교체하지 않는다. 원본과의 유사도는 사용자의 시각 판단을 포함하며 임의의 자동 점수로 대체하지 않는다.
3. **관절 연결·포즈 검증**
   - 외형을 확인한 뒤 기존 리그에 연결한다. 분할 경계는 관절 축과 접힘 방향을 기준으로 정한다.
   - 팔 올림·허리 손짚기·쪼그림·무릎꿇기·비틀기에서 어깨 탈락, 무릎 뚜껑, 손목 단차, 과도한 자기 침투를 캡처로 점검한다.
   - 부위 치수 유지, 뼈 길이 유지, 관절 제한은 기존 자동 검사를 계속 사용한다. 외형 합격과 기능 합격을 별도로 기록한다.
4. **체형 확장과 앱 통합**
   - 기준 외형을 확인한 다음 키·5/8/9.5등신·가슴 설정을 확장한다. 단순 전체 스케일로 해부학 형태가 무너지지 않는지 검사한다.
   - 기존 직접 편집·저장 포즈·Undo/Redo·Save/Load·컬러/깊이 전달 묶음을 회귀 검증한다.
   - 현행 모델과 같은 장면·해상도에서 렌더 시간, 호출 수, 삼각형 수, 포즈 조작 반응을 비교한다. GPU가 약한 PC를 고려해 세부 단계와 필요할 때만 다시 그리기를 유지한다.

## 다음에 보여줄 결과

다음 결과물은 완성 선언이나 대규모 회귀 검사 목록이 아니라 **동일 포즈의 원본/시제품 대조, 실루엣 겹침, 중립 자세의 여러 방향 캡처**다. 이 단계에서 형태가 맞지 않으면 조형을 수정한다. 외형을 확인하기 전에 앱 통합과 배포를 반복하지 않는다.

이 문서는 재설계 계획이며, 새 메시 제작·외형 합격·재빌드를 완료했다는 보고가 아니다.
