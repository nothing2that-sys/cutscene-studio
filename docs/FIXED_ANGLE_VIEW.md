# 3D 편집과 2.5D 고정 앵글 보기

전신으로 확장한 후속 시제품: [전신 작화 인형 — 3D 포즈 / 2.5D 선화](FULL_DOLL_PROTOTYPE.md), 실행 `/doll-full.html`.

2026-11-03. 실행: http://127.0.0.1:3001/doll-core.html

사용자가 제안한 **3D로 방향/자세를 잡고, 고정 앵글에서는 투영 이미지를 이동·확대하는 방식**을 중심 부품 시제품에 추가했다. 3D 형상은 편집 원본으로 유지한다. 표시는 회색 음영 외에 선화·단색 면을 선택할 수 있다.

## 사용

1. 기존 방향 선택이나 `3D 보기`로 앵글을 정한다. 고정 모드에서 3D로 복귀하면 `마우스 회전`이 활성화된다.
2. 위쪽 **조작 → 2.5D · 앵글 고정**을 선택한다.
3. **선화 / 단색 면 / 현재 3D 음영**을 선택한다. 구조선은 켜거나 끌 수 있다.
4. 드래그로 화면 이동, 휠이나 확대 슬라이더로 확대/축소한다. X/Y/Z 입력은 모델의 세계 좌표 이동이다. 실제 단위(cm)가 확정된 모델이 아니므로 보기 단위로 표시한다.
5. 다시 `3D 보기`로 돌아가면 앵글과 화면상 이동·확대 상태를 유지하면서 회전할 수 있다. `현재 보기 PNG`로 현재 화면을 내보낸다.

`이동·확대 초기화`는 고정 보기의 화면 이동/확대와 모델 XYZ 이동을 초기화한다. `투영 갱신`은 같은 앵글의 이미지를 다시 만든다. 부품/포즈/형상/방향/크기가 바뀌면 투영도 갱신한다.

## 이번 구현에서 재사용하는 것

| 조작 | 동작 |
|---|---|
| 고정 앵글에서 드래그·휠 확대 | 저장한 투영 레이어를 합성. WebGL 재렌더 없음 |
| 고정 앵글에서 모델 전체 X/Y/Z 이동 | 고정 카메라의 우측/상방 축에 투영한 이동을 레이어에 적용. 실제 3D 위치도 유지 |
| 포즈·형상·표현·앵글 변경 | 3D를 새로 그려 투영 레이어 갱신 |
| 3D 보기 복귀 | 화면 팬/줌을 정사영 카메라로 옮겨 동일한 화면 위치 유지 |

현재 카메라는 정사영이다. 따라서 정면 앵글에서 Z만 이동하면 화면 크기는 그대로인 것이 정상이다. 사선 앵글에서는 세계 Z 이동도 화면상 이동으로 나타날 수 있다. 확대는 별도의 줌 조작이다. 원근 카메라를 쓰면 깊이 이동에 따른 부위별 원근 변화가 생길 수 있어 같은 정확성을 전부 단순 스케일로 보장할 수는 없다.

이것은 **고정 앵글의 투영 이미지 방식으로 만든 2.5D 보기**다. 모델 자체를 영구적으로 평면화하거나 새 2D 작화 모델로 바꾼 것은 아니다.

## 선화·단색 면

실제 3D의 가시 표면 법선/외곽에서 선을 얻고, 선택적으로 쇄골·가슴 아랫면·몸통 중심의 구조선을 더한다. 구조선은 현재 조형의 표면에 놓고 실제 메시 가림을 확인해 표시한다. 원본 그림을 따라 보이지 않는 부위를 새로 그리거나 3D 모양을 보정하는 기능은 아니다. 선 표현으로 기존 형상 문제를 해결했다고 주장하지 않는다.

선화와 단색 면의 투영은 표시 크기의 2배 해상도로 만들어 재사용한다. 이동·확대 중에는 새 3D 렌더를 하지 않는다. 투영 생성 시에는 컬러/법선 렌더 및 선 추출 작업이 발생한다. 큰 확대에서는 픽셀 이미지의 한계가 남으며 벡터 원화로 바뀐 것은 아니다.

## 범위와 남은 작업

현재는 중심 부품 조립체 전체를 하나의 레이어로 다룬다. **다른 인물·물체와의 앞뒤 관계, 부품별 독립 이동, 서로 교차하는 가림**까지 이미지 레이어만으로 해결한 상태는 아니다. 본 편집기에 확대 적용할 때는 물체별 컬러/깊이 투영과 가림 갱신이 필요하다. 같은 이유로 카메라 회전이나 새 포즈는 재투영한다.

XYZ 이동은 실제 3D 배치에 반영되어 OBJ에도 포함된다. 보기의 카메라·팬·줌은 현재 페이지 상태이며 조형 JSON에 저장하지 않는다. 기존 앱의 저장 포즈/JSON 형식이나 기본 모델은 변경하지 않았다.
