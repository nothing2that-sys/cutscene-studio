# 가슴 위치와 형태 참조

현재 편집기는 사용할 수 있으며, 여성 인물 등의 가슴 위치가 누락되던 참조를 보완했습니다. 공통 마네킹 리그 위에 선택적으로 두 입체 형태를 붙입니다. 완전한 여성 인체 리그나 의복·연부 조직 시뮬레이션은 아닙니다.

## 사용

인물 선택 → 오른쪽 **인물 체형 설정** → **가슴 형태 참조** 펼치기 → **가슴 형태 표시** 체크 → 높이·간격·돌출 조절 → **체형 적용**. 인물별 설정이며 다른 인물에 영향을 주지 않습니다. 키·등신 변경과 함께 저장되고 Undo/Redo·Load·개별 인물 불러오기에 동일하게 복원됩니다.

바로 확인하려면 [예제 장면](../examples/chest-reference.json)을 왼쪽 **장면 JSON 열기**로 불러오세요.

장면 JSON의 인물에 선택적으로 추가합니다. 생략하면 참조 형태를 만들지 않습니다.

```json
"chest": {"height":0.65,"spacing":0.46,"projection":1}
```

| 필드 | 의미 | 범위 |
| --- | --- | --- |
| height | 흉곽 로컬 높이에 대한 비율 | 0.55~0.78, 기본 0.65 |
| spacing | 흉곽 너비 대비 좌우 체적 중심 간격 | 0.3~0.6, 기본 0.46 |
| projection | 앞쪽 돌출 배율 | 0.4~1.6, 기본 1 |

수치는 이 마네킹의 편집용 비율이며 인체의 표준 측정값이 아닙니다. 형태는 단순 타원체이며 체적 중심을 유두 위치로 해석하지 않습니다. 필요한 위치는 캐릭터 정본에 맞춰 사용자가 조절합니다. 성별 이름으로 자동 추가하지 않습니다.

## 포즈와 전달

형태는 흉곽 좌표계에 붙어 굽힘·회전을 따라가며 포즈 중 독립 이동하지 않습니다. 뼈 길이와 키/등신 측정에 영향을 주지 않습니다. 순수한 마커가 아니라 실제 지오메트리이므로 컬러·깊이 촬영에 포함됩니다. 깊이 PNG는 8비트 선형 표현이어서 정면의 얕은 돌출은 양자화로 잘 구분되지 않을 수 있습니다. 컬러 PNG와 사선 구도를 함께 참고하세요.

전달 묶음의 `anatomyReferences`에는 인물 ID·이름, 좌우 체적 중심의 월드 미터 좌표, 촬영 카메라로 투영한 `leftImage`/`rightImage` 좌표가 들어갑니다. 화면 좌표는 왼쪽 위 원점의 0~1 비율입니다. `inFrame`은 프레임 범위 검사이며 팔·옷·다른 인물에 가렸는지는 판정하지 않습니다. 실제 수정 설정은 `editorState.mannequins[].bodyProfile.chest`에 저장됩니다.

작화에는 캡처의 흉곽 위치·간격·원근·가림을 유지하고 의상만 입히도록 지시합니다. 이 참조만으로 이미지 생성 모델이 정확한 위치를 보존하는 것은 아니므로 생성 결과를 캡처와 대조해야 합니다.

## 검증

`node scripts/chest-reference-check.mjs`는 3001 정적 서버와 3002 Vite 서버에서 실제 3D와 브라우저를 검사합니다. 흉곽 추종, 로컬 위치 고정, 뼈 길이·키·등신 유지, 인물별 독립 설정, Undo/Redo·저장 왕복, 컬러/깊이의 실제 형태 차이, 촬영 좌표와 해제를 확인합니다. 단위 테스트는 잘못된 장면·정밀 프로젝트 설정을 거부하는지도 검사합니다. 증거는 `validation/chest-reference/`에 생성됩니다.
