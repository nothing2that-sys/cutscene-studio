# 작화 인체 v1 작업 인계 — 2026-11-04

현재 상태는 **메인 편집기 통합을 구현한 중간 결과**이며, v1 종결 통과가 아니다. 사용자의 현황 정리·커밋 지시에 따라 현재 제품 소스를 보존한다.

## 중단 원인

구현 조정 에이전트와 검사 관측 보완 에이전트가 `Selected model is at capacity. Please try a different model.` 오류로 종료됐다. 자동 재개되지 않았다. 후속 A 회차 정리와 새 버전 B 재현이 완료되지 않았으며, 이미 경과한 시간을 새 검증 예산으로 초기화하지 않는다.

## 구현된 결과

- 머리·몸통·골반·팔다리·단순 손발을 포함한 관절 인체를 메인 편집기의 기본 인체로 연결했다. 손발 세부는 인물 설명으로 전달하며 관절·굽힘 데이터는 유지한다.
- 3D 포징 후 작업/촬영 앵글을 고정해 장면 전체를 2.5D 선화로 표시한다. 고정 상태 팬·줌은 캐시 변환이며 자세·위치·가림 변경은 새 투영으로 처리한다.
- 명시 관절 자세, 구 rest revision 변환, 기존 인체 호환, 저장·재열기·Undo/Redo·설명 전달을 연결했다.
- 마지막 보완에서 숨은 구형 메시 때문에 기본 인체가 화면 밖에 배치되던 문제, GLB Undo 복원 직후 저장 시 소품이 빠지던 문제를 수정했다. 복원은 준비 후 장면 교체 방식이며 잘못된 파일을 장면 교체 전에 거절한다.
- 실제 방 벽·바닥을 선화 가림에 포함하고 카메라 줌/view, near/far 클리핑, 촬영 화면 갱신과 포즈 파일 호환을 보완했다.

## 확인한 범위

마지막 제품 manifest SHA256은 `7411b942511a1a59c28d697f97b01bf923900ee6006fb7311819220362dd7f0d`다. 로컬 원문은 `validation/body-v1-postVB-20261104/`에 보존돼 있다. 이 폴더는 Git 제외 대상이므로 커밋에 포함되지 않는다.

- 마지막 구현자 실행에서 빌드와 기존 테스트 17개가 통과했다. 커밋 직전에는 실제 소스/자산 56개를 manifest와 재대조해 불일치 0을 확인하고 기존 scene-format 테스트 3개와 production 빌드를 다시 통과했다. 빌드에는 기존 대용량 chunk 경고가 있으며, diff 검사에는 시제품 파일 5개의 EOF 빈 줄 경고가 남아 있다.
- 구현자 실제 브라우저 재현: 기본 인체 정점 14968/14968 화면 안, 연속 Undo/Redo 직후 저장·재열기에서 GLB 1개 유지, 잘못된 입력 원자 거절, 명시 자세 및 카메라 왕복을 확인했다. 이는 독립 종결 판정을 대체하지 않는다.
- 새 버전의 독립 바인딩 제한 재대조는 중립 rest·표면 접합·anchor·가변 버퍼 분리와 명시 자세 왕복을 확인했다. 전체 품질 판정이 아니다.
- 이전 제품 버전에서는 등록 13개 자세의 CONTACT/F1 및 메인 F4/F1, 선화·캐시 사용 흐름을 부분 확인했다. 이전 버전의 결과와 성능을 현재 버전의 전체 통과로 옮기지 않는다.

## 남은 문제와 검증 공백

새 A 1회차는 정식 출력 검사까지 완료됐으나 중간 심각도 6건으로 계속 판정이었다. 2회차 반환은 있으나 조정 에이전트 오류로 정식 회차 저장·검사·비교가 끝나지 않았다. 수렴 또는 통과로 부르지 않는다. 추가 검토 지적은 아직 제품에서 독립 재현·수정되지 않았다.

검토에서 지적한 주요 잔여 영역은 고정 작업 화면의 팬·줌을 컷 저장/기존 Generate Image 경로에 반영하는 문제, 구형 프로젝트 전환 시 고정뷰 초기화, 크기 변경 시 선화 캐시, 추정 자세 재적용 시 카메라 초기화, 복원 중 Delete 입력, 기본 포즈의 골반 방향 및 키 변경 시 발 지지 보존이다. 이 목록은 검토 지적이며 모두 실제 재현을 마친 확정 결함 목록은 아니다.

환경 가림의 독립 검사 보완 후보는 제한 심사에서 추가 반례가 나와 미채택 상태다. 기존 동결 검사 원본은 보존돼 있다. 제품 자체의 환경 가림 재현을 검사 후보 통과로 표현하지 않는다.

새 제품 버전의 최종 B 통합 재현·공식 성능, 모든 지원 입력 범위의 삼각형 접촉 검사, 이전 버전과 동일한 가시 장면의 성능/지원 보존 비교는 미완료다. 숫자와 등록 자세 일부의 통과가 최종 실루엣 채택을 의미하지 않는다.
