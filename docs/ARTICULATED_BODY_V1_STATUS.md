## 관절 좌우 수정 — 2026-11-04 (`431f7f2` 이후)

인체 자산의 `L/R` 뼈 이름은 정면 참고 이미지 기준이라 `L` 뼈가 인물의 해부학적 오른쪽에 있다(발끝 방향 기준, 실제 렌더로 확인). 그런데 adapter가 `l_arm → upperL`처럼 같은 글자로 연결해, 장면 JSON·UI의 `l_`(문서상 인물 기준 왼쪽)이 인물의 오른쪽 팔다리를 움직였다.

- `body-v1-adapter.js`: driver 키를 반대 글자 뼈에 연결한다(`l_arm → upperR` …). 기존 basis는 반대 키의 것에 native Z 반바퀴를 합성해 재사용한다. mannequin.js의 l/r DOF가 native Z에 대해 거울 관계라, 각 값의 해부학적 의미(raise 앞, straddle 음수 바깥, 무릎 뒤로)가 그대로 올바른 쪽에 적용된다. 메시 클릭 부위 이름과 `body-surface.js` 부위 범위도 같은 기준으로 바꿨다.
- 저장: `bodyV1Pose.driverSideRevision: 2`. 이 필드가 없는 이전 저장은 열 때 driver 값과 잔차를 반대 키로 옮긴다. 표시 인체는 그대로이고(정점 차 1e-15 수준), 이전 `l_arm` 값은 `r_arm`에 나타난다. 손목 `tilt`만 mannequin.js 규약상 거울 대칭이 아니어서 같은 자세가 부호 반대 숫자로 보인다.
- 확인: `scripts/body-sides-check.mjs`(실제 브라우저). 양쪽 팔·다리 raise/straddle이 해당 쪽·앞·바깥으로 가는지, 수정 전 빌드로 저장한 `scripts/fixtures/pre-side-fix-project.json`이 같은 정점으로 열리는지 본다. 수정 전 빌드에서는 실패한다(음성 대조). 기존 테스트 27개, build, browser-check, validation-ui-check 통과. body-rig-check는 수정 전에도 같은 체형 높이 측정 오류로 실패한다.
- 이미지 레퍼런스 변환 포즈(`app/public/local-pose-references`)와 bodyAsset 없는 포즈 JSON은 legacy Male native 절대 회전값이다. 인체 v1은 큰 조합 회전을 legacy와 다르게 해석해, 좌우 수정 전에도 팔다리가 몸 안쪽으로 교차하는 자세가 나왔다(수정 전후 결과가 서로 거울상일 뿐 둘 다 원본과 다름). 이제 `pose-library.js`가 숨은 legacy 인형에서 자세를 평가한 뒤 몸통·어깨·팔다리의 world 방향을 인체 v1에 맞춘다(관절 한계 안에서 국소 탐색). POSE-0051 기준 legacy 대비 최대 4.5°, 이 변환 없이 128°. 실제 화면에서 POSE-0051·0002·0015·0041·0055가 원본 그림과 맞았다. POSE-0040은 legacy 인형에서도 다리가 틀린 `unresolved` 변환 자료다.

## 구현된 결과

- 머리·몸통·골반·팔다리·단순 손발을 포함한 관절 인체를 메인 편집기의 기본 인체로 연결했다. 손발 세부는 인물 설명으로 전달하며 관절·굽힘 데이터는 유지한다.
- 3D 포징 후 작업/촬영 앵글을 고정해 장면 전체를 2.5D 선화로 표시한다. 고정 상태 팬·줌은 캐시 변환이며 자세·위치·가림 변경은 새 투영으로 처리한다.
- 명시 관절 자세, 구 rest revision 변환, 기존 인체 호환, 저장·재열기·Undo/Redo·설명 전달을 연결했다.
- 마지막 보완에서 숨은 구형 메시 때문에 기본 인체가 화면 밖에 배치되던 문제, GLB Undo 복원 직후 저장 시 소품이 빠지던 문제를 수정했다. 복원은 준비 후 장면 교체 방식이며 잘못된 파일을 장면 교체 전에 거절한다.
- 실제 방 벽·바닥을 선화 가림에 포함하고 카메라 줌/view, near/far 클리핑, 촬영 화면 갱신과 포즈 파일 호환을 보완했다.

- 이전 제품 버전에서는 등록 13개 자세의 CONTACT/F1 및 메인 F4/F1, 선화·캐시 사용 흐름을 부분 확인했다. 이전 버전의 결과와 성능을 현재 버전의 전체 통과로 옮기지 않는다.

## 남은 문제와 검증 공백

새 A 1회차는 정식 출력 검사까지 완료됐으나 중간 심각도 6건으로 계속 판정이었다. 2회차 반환은 있으나 조정 에이전트 오류로 정식 회차 저장·검사·비교가 끝나지 않았다. 수렴 또는 통과로 부르지 않는다. 추가 검토 지적은 아직 제품에서 독립 재현·수정되지 않았다.

검토에서 지적한 잔여 영역(고정 작업 화면 팬·줌의 컷/Generate Image 반영, 구형 프로젝트 고정뷰 초기화, 크기 변경 캐시, 추정 자세 재적용 카메라, 복원 중 Delete, 기본 포즈 골반·키 변경 발 지지)은 위 「후속 구현 세션 결과」에서 모두 실제 재현 후 수정했다. 구현자 확인 범위이며 독립 재현은 아니다.

환경 가림의 독립 검사 보완 후보는 제한 심사에서 추가 반례가 나와 미채택 상태다. 기존 동결 검사 원본은 보존돼 있다. 제품 자체의 환경 가림 재현을 검사 후보 통과로 표현하지 않는다.

새 제품 버전의 최종 B 통합 재현·공식 성능, 모든 지원 입력 범위의 삼각형 접촉 검사, 이전 버전과 동일한 가시 장면의 성능/지원 보존 비교는 미완료다. 숫자와 등록 자세 일부의 통과가 최종 실루엣 채택을 의미하지 않는다.
