실행 화면: http://127.0.0.1:3001/body-study.html

## 실제 제작 경로

Blender는 PATH 및 `C:/Program Files/Blender Foundation`에서 발견되지 않았다. 모든 디스크의 설치 여부를 확인한 것은 아니다. 이번에는 별도의 `body-study-cage.js`에 저해상도 XYZ 제어점을 조형하고 Three.js에서 보간한 실제 입체 메시를 만들었다. 기존 `segmented-body.js`의 수치나 메시를 재사용하지 않았다.

목·쇄골 폭·흉곽·가슴 부착부·가슴 아랫면·늑골 아래·허리·장골·골반 하부를 각각 편집할 수 있는 단면으로 구성했다. 가슴은 별도 구 없이 몸통과 같은 토폴로지 안에서 돌출한다. 팔다리는 앞뒤 깊이와 중심 이동이 다른 단면으로 구성하고 팔꿈치·무릎 단면을 공유한다. 손바닥·손가락·발·발가락은 별도 제어점 메시다. 어깨/몸통, 골반/다리, 손목/손, 발목/발은 아직 서로 용접된 단일 메시가 아니다.

화면에서 부위 → 단면 → 둘레 점을 선택해 XYZ 좌표를 수정할 수 있다. 토폴로지 보기에서 선택점을 표시한다. JSON 저장·재열기·초기화를 제공하며, 자세별 편집은 페이지를 닫기 전까지 별도로 유지한다. 영구 보관은 JSON 저장을 사용한다. 기존 앱 포즈 JSON과 다른 조형 전용 형식이다.

## 비교 조건과 추정

원본은 960×1280, 렌더는 480×640이며 웹 화면에서는 둘을 같은 크기로 표시한다. 프레임 전체를 사용하고 임의로 모델만 자동 확대하지 않는다. +Z에서 보는 정사영이다. 원본 카메라를 복원한 결과는 아니다. 원본의 사선 투영과 비대칭은 우선 비교 자세의 제어점 배치에 반영했다.

`landmarks.json`에는 원본에서 수동으로 판독한 머리 꼭대기·턱·양쪽 어깨·팔꿈치·손목·고관절·무릎·발목과 실제 카메라 투영 좌표를 기록했다. 고관절 중심은 특히 추정이다. 이 점들은 모델 작성에 사용한 목표 좌표이므로 관절점이 일치하는 것은 독립적인 외형 검증이나 정확도 점수가 아니다. 관절 중심과 별개로 실루엣 겹침을 검토해야 한다.

원본은 한 장의 선화다. 깊이, 가려진 흉곽, 등, 둔부, 손발의 숨은 면은 설계 추정이다. 중립 자세는 같은 단면을 재배치한 별도 조형 상태이며, 동일 리그를 움직여 얻은 중립 자세가 아니다. 중립 체형은 약 8등신이다. 원본 비교 자세에서는 원본의 머리 비례를 유지하므로 같은 등신 수치로 억지 보정하지 않았다. 키를 확정한 실물 치수 설계는 아니다.

## 직접 확인 후 수정한 내용

첫 캡처에서는 비교 캔버스의 고정 CSS 크기 때문에 겹침 크기가 어긋났고, 숨긴 이미지가 CSS에 의해 계속 표시되었다. 캔버스와 이미지의 표시 크기를 통일하고 숨김 처리를 수정했다. 첫 메시의 잘린 어깨 끝은 상완 시작 단면을 추가해 덮고, 팔꿈치·무릎의 별도 끝막음 대신 공유 단면으로 바꿨다. 허리 손의 손가락 방향과 발 폭을 수정하고 발가락을 추가했다. 표시 해상도를 낮추고 변경 때에만 그린다. 변경 전 시안을 외형 성공의 증거로 삼지 않는다.

## 남은 외형 차이 — 합격 판정 아님

| 항목 | 현재 관찰과 다음 조형 |
|---|---|
| 쇄골·어깨·겨드랑이 | 잘린 팔 끝은 줄었지만 몸통과 삼각근이 만나는 틈과 단차가 남는다. 쇄골 능선과 겨드랑이 앞뒤 주름의 실제 연결 토폴로지가 필요하다. |
| 가슴·흉곽 | 별도 공은 제거했지만 앞면 볼륨과 아랫면이 뭉툭하고 좌우 형태가 원본보다 대칭적이다. 원본의 오른쪽 가슴 실루엣과 늑골 흐름을 더 조형해야 한다. |
| 복부·골반 | 허리에서 장골로 이어지는 외곽을 만들었으나 골반 하부는 옷자락처럼 보이는 경계가 남는다. 고관절 구멍을 가진 용접 토폴로지와 서혜부 설계가 필요하다. |
| 팔꿈치·무릎·다리 | 원본의 무릎 관절 외형과 뼈/근육 구분은 아직 약하다. 공유 단면은 접힘의 해부학적 정확성을 보장하지 않는다. 종아리 바깥 곡선과 정강이 평면도 보완해야 한다. |
| 손·발 | 손가락은 단순화되어 원본처럼 손등과 손가락이 자연스럽게 이어지지 않는다. 발은 정면에 맞춘 길고 넓은 형상이어서 측면에서 발등·발바닥이 거칠고 신발처럼 보인다. 발가락 추가만으로 해부학 형태가 해결된 것은 아니다. |
| 후면·측면 | 등과 둔부는 원본에서 확인할 수 없는 가정이며 평평하거나 부풀어 보이는 부분이 있다. 중립 사선의 골반 경계도 뚜렷하다. |

이 시제품은 원본 수준의 조형에 도달하지 못했다. 다음 외형 수정은 특히 어깨·서혜부 접속과 손발의 입체 구조에 집중해야 한다. 승인된 기준 체형으로 취급하지 않는다.
