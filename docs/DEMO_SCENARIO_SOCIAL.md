# X 기능 소개 · 빠른 편집본

목적: 사용 가능한 기능을 짧게 보여준다. 가로형 16:9, 약 42초, 14개 컷, 무음으로 봐도 이해할 수 있는 한국어 자막. 최종 작화로 먼저 관심을 끌고, 실제 편집기 조작과 생성 비교를 연결한다.

| 시간 | 내용 | 화면 |
| --- | --- | --- |
| 0–2초 | 결과부터 보여주기 | 3D 참조와 외부 작화 |
| 2–5초 | 장면 불러오기 | 실제 JSON 파일 적용 |
| 5–8초 | 기본 포즈 변경 | 무릎 꿇기 → 눕기 |
| 8–10.5초 | 포즈 저장 | 포즈 JSON 다운로드 |
| 10.5–12.5초 | 기본 자세로 복귀 | 서기 적용 |
| 12.5–15초 | 저장 포즈 복원 | 포즈 JSON 불러오기 |
| 15–18.5초 | 내 포즈 라이브러리 | 이름을 붙여 담기 → 카드 적용 |
| 18.5–21.5초 | 카메라 구도 | 드래그 → 구도 저장 |
| 21.5–24.5초 | 거리 참조 | 깊이 → 거리 색·링, 실제 출력 확대 |
| 24.5–27.5초 | 광원 참조 | 실제 직사광·그림자 출력 확대 |
| 27.5–30.5초 | 전달 패키지 | 실제 ZIP 다운로드 |
| 30.5–34.5초 | 거리 전달 비교 | 컬러만 / 깊이·거리 설명 추가 |
| 34.5–38.5초 | 조명 전달 비교 | 컬러만 / 조명 참조·설명 추가 |
| 38.5–41.5초 | 결과와 저장소 | 3D 참조 → 외부 작화, GitHub 주소 |

대기·로딩 구간을 컷으로 제거하고 컷별 속도를 맞춘다. 포즈 조작 부분은 편집 시 화면을 확대한다. 거리·광원 미리보기는 실제 출력을 영상 촬영용으로 확대해 읽기 쉽게 보여준다. 비교 카드는 기존 실험 결과이며 새로 생성한 실시간 결과로 표현하지 않는다. 거리 비교의 수치는 조건별 3회 평균이고, 조명은 일부 성공 예이며 전체 판정이 불확실하다는 점을 화면에 표시한다.
