# 개발 과정과 검증 기록

이 공개 저장소는 현행 구현·개발 문서와 [개인정보를 정리한 실제 개발 커밋 61개](COMMIT_HISTORY.md)를 포함한다. 최초 공개 스냅샷과 영상 업데이트 커밋을 보존하고, 원본 이력에서 개인 첨부물·재배포 제외 포즈 데이터와 개인 식별 정보를 정리한 계보를 병합했다. 문서 속 과거의 비공개 인계·로컬 경로·실험 상태는 당시 기록이며 현재 공개 설치 방법은 루트 README를 따른다.

기술 문서에는 실패·한계·중간 대안도 포함한다. 특정 시점의 기록을 현재 완성도나 지원 보장으로 읽지 않도록 문서 날짜와 현행 코드를 함께 확인한다. 공개본의 텍스트에는 개인 로컬 경로와 연락처를 일반 경로로 치환했다. 외부 포즈 원본·개인 첨부·사용자 세션 파일·자격 증명·대형 로컬 저장 프로젝트는 공개본에서 제외한다.
