# 466개 원본 대조 보정 결과 — 2026-11-02

466개 모두 원본 PNG와 실제 마네킹 렌더를 나란히 놓고 확인했습니다. **205개는 장면 배치용 근사 포즈로 등록**, **261개는 미해결 초안으로 분리**했습니다. 466개가 전부 원본과 일치하도록 해결된 것은 아닙니다. 보정 시도 자체와 사용 가능 판정을 구분했습니다.

## 사용

실행 중인 앱을 새로고침하고 인물을 선택한 뒤 **이미지 레퍼런스 → 원본 대조 · 보정본**을 선택하세요. 보정본은 카드 클릭으로 선택 인물에 적용됩니다. 기본 `바로 적용 가능` 목록은 기존 검수 전 추정 535개와 이번 보정본 205개, 총 740개입니다.

**미해결 · 수동 확인**에는 261개만 나타납니다. 카드를 누르면 원본과 남은 차이를 보여주며 자세는 변경하지 않습니다. 원할 때만 **미해결 초안 직접 적용**을 누르세요. 직접 수정한 자세는 **현재 3D 자세를 연결해 저장**으로 원본 번호에 연결할 수 있습니다.

## 보정과 판정 근거

- 최초 `needs-correction` 466개 ID를 고정하고 원래 변환을 로컬에 보관했습니다.
- 독립 RTMPose-X 2D 모델로 원본을 0/90/180/270도 회전해 재추정했습니다. 신뢰도가 높은 두 관측과 세 가지 깊이 비율을 조합하여 6개 초기 자세를 비교하고, 뼈 길이·루트 위치를 고정한 채 큰 관절을 이미지 투영에 맞췄습니다.
- `app/src/reference-edits.json`에는 원본을 보고 지정한 개별 자세·지지·접촉·참조 시점 보정이 있습니다. 같은 분류 전체를 하나의 포즈로 덮지 않았으며, 일부는 유사한 개별 참조의 하체 또는 팔만 출발점으로 사용했습니다.
- 원본+보정 후보 16개씩, 총 30장의 비교 시트를 시각적으로 검토했습니다. 자동 점수만으로 승인하지 않았습니다. 개별 결정·원본 해시·후보 해시는 `reviews.json`, 최종 JSON 해시는 `data/pose-corrections/index.json`에 남겼습니다.
- 부감·앙각 참조 카메라는 렌즈 보정값을 알 수 없는 **근사 시점**입니다. 포즈 적용 시 단독 편집 시점을 맞추며 저장된 작업 카메라와 촬영 컷은 보존합니다.

사용 가능 판정은 **몸통과 큰 관절 동작을 장면 배치에 사용할 수 있는 근사 수준**입니다. 픽셀 일치, 가려진 깊이, 손가락·시선, 의자/상자 크기에 따른 접촉, 미세 손발 접촉, 무게중심의 정확성을 보장하지 않습니다. 강한 원근, 가려진 팔다리, 좁은 손 접촉에서 큰 차이가 남은 것은 미해결로 유지했습니다.

## 재적용과 재현

일반 앱 실행에는 추론 모델·Python이 필요하지 않습니다. 이번 466개 파생 포즈 JSON과 판정은 비공개 저장소의 `data/pose-corrections/`에 포함합니다. 원본 PNG·원시 추론·모델은 Git에서 제외합니다.

다른 PC에서는 개인 원본 이미지와 기존 1001개 변환을 준비한 뒤 프로젝트 최상위에서 실행하세요.

```powershell
node scripts/apply-reference-corrections.mjs
npm --prefix app run build
```

재적용 도구는 전체 원본 이미지·목록·패치 해시와 포즈 형식을 먼저 검사한 뒤 씁니다. 기존 535개는 건드리지 않습니다. 자료가 없는 새 클론에서 원본을 자동 다운로드하지 않습니다.

새롭게 추론/보정을 재실행하려면 최초 catalog와 466개 변환 사본을 `.review-tools/reference-correction-baseline/`에 보관하고, 2D 모델을 설치한 후 `refine-reference-landmarks.py` → 소스 서버 3002 → `refine-reference-poses.mjs` → `render-pose-audit.mjs --refined` 순으로 실행합니다. 후보가 바뀌면 반드시 새 시각 검토 해시를 기록해야 `publish-reference-corrections.mjs`가 허용합니다. 자동 점수 개선을 검수 완료로 취급하지 않습니다.
