# Drive 이미지 레퍼런스

[제공 폴더]([private-reference-omitted])의 검색 태그와 개별 PNG 백업을 등록했습니다. 1,001개·분류 20개이며 원본의 변형·중복·비고를 유지합니다. 모든 PNG의 SHA-256을 목록과 대조했습니다.

**이미지 레퍼런스**에서 번호(`POSE-0251`)·자세·장면으로 검색하거나 분류를 고릅니다. 36개씩 표시하고 이미지를 지연 로딩합니다. 카드를 선택하면 편집 화면 옆에 고정하고 단독 포즈 모드로 들어갑니다. 원본의 작은 관절·좌우·접촉은 직접 확인하세요. 감정·장면 태그는 검색용 추정입니다.

원본은 2D 이미지이며, **3D 변환이 있는 카드**는 선택 시 현재 인물에 추정 자세를 적용합니다. 원본을 보며 보정한 뒤 **현재 3D 자세를 연결해 저장**을 누르면 원본 POSE 번호와 연결해 **내 포즈**에 저장합니다. 이후에는 수정한 내 포즈를 재사용하세요. 연결 정보도 백업에 포함합니다. 같은 자세가 이미 있으면 이름·연결을 갱신합니다. `검수 전`·`보정 필요` 표시는 정확한 원본 복원을 보증하지 않는다는 뜻입니다. [변환 방식과 품질 제한](POSE_CONVERSION.md).

원본·태그는 `app/public/local-pose-references/`에 보관하고 Git에서 제외합니다. 빌드하면 dist에 복사되므로 Drive 로그인·외부 네트워크 없이 사용합니다. 다른 PC에서 클론하면 자료를 다시 내려받아 등록하세요. 제공 자료의 개인 참조 범위를 유지하며 공개 재배포 권한을 추가하지 않습니다.

1. Drive의 `21_검색태그_20261030/pose-tags.json`을 위 로컬 폴더에 둡니다.
2. `00_원본과목록/포즈_개별PNG_백업.zip`을 풀고 개별 PNG 1,001개를 위 폴더의 `images/`에 모읍니다. 파일명을 유지합니다.
3. 루트에서 `node scripts/register-image-references.mjs` 실행. 누락·중복·해시 불일치는 실패하며 성공하면 catalog.json을 만듭니다.
4. `npm --prefix app run build` 후 실행기를 엽니다. 기존 페이지는 작업과 라이브러리를 저장한 뒤 새로고침합니다.

원본 설명은 Drive의 `00_원본과목록/사용안내.txt`, 태그 설명은 `21_검색태그_20261030/사용안내.md`에 있습니다. 다른 PC에서 3D 변환까지 재현하려면 [변환 안내](POSE_CONVERSION.md)를 따릅니다. 전체를 사람이 수동 검수한 데이터셋은 아닙니다.
