# LLM 패키지 효과 검증 절차서 (GPT · Gemini)

## 무엇을 확인하나

**가설:** LLM 패키지(라벨·뎁스·조명·포즈 이미지와 지시문)를 주면, 컬러 캡처 한 장과 줄글 설명만 줄 때보다 구도·인원 배치·포즈·명암을 더 정확히 따른다.

그래서 각 장면을 두 가지 조건으로 그려 비교합니다.

| 조건 | 넣는 것 |
|---|---|
| **A · 패키지** | zip 안의 이미지 5장 + `prompt.txt` 내용 |
| **B · 대조군** | `control-color.png` 1장 + `control-prompt.txt` 내용 (장면 설명과 인물 외형만) |

두 조건의 지시문 맨 앞에 **같은 화풍 문장**이 들어 있습니다(기본값: 2D 웹툰 일러스트, 선화와 셀 채색, 실사·3D 질감 금지).

1차 시도(2026-11-06)에서는 대조군 지시문에만 "일러스트"라는 말이 있었습니다. 그래서 나노바나나가 A는 실사·3D로, B는 2D로 그려 비교할 수 없었습니다. 이제 두 조건 모두 같은 문장으로 화풍을 고정합니다. 다른 화풍으로 시험하려면 장면 JSON의 `style`(또는 패널의 「화풍」)을 바꾸세요.

- 장면 4개 × 모델 2개(GPT, Gemini) × 조건 2개 = 결과 이미지 **16장**입니다.
- 시간이 부족하면 S2와 S4만 먼저 해도 됩니다. 조명과 좌우 판정이 가장 뚜렷하게 갈리는 장면입니다.

## 사전 자동 검증 (완료)

`scripts/llm-package-scenarios.mjs`로 네 장면의 패키지를 만들고 48개 항목을 자동 검사했습니다. 모두 통과했습니다.
- 인물이 라벨에 보이는지
- 뎁스 순서와 관절 거리 순서가 같은지
- 뼈대가 라벨 영역 안에 있는지
- 전등 밝기 순서, 그림자 주체
- 스포트 원 안/밖, 앉은 자세
- 역광 판정, 오른손의 화면 쪽
- 무릎 꿇은 인물의 방향

이 과정에서 찾아 고친 문제:
1. **무릎 꿇은 인물의 방향이 반대로 계산됨:** 정강이가 뒤로 누우면서 발끝이 뒤를 향해 "카메라 정면을 향함 · 빛을 등짐"으로 잘못 나왔습니다. 굽힌 무릎 방향으로 판정하도록 고쳤습니다.
2. **pose.png 인물 이름이 겹치거나 화면 끝에서 잘림:** 화면 안에 두고, 겹치면 위로 쌓도록 고쳤습니다.
3. **미리보기 패스가 느림:** 편집 중 패스 미리보기가 약 0.85초씩 멈췄습니다. 보는 패스만 계산하고 편집이 멈춘 뒤 갱신하도록 바꿔 약 0.2초가 됐습니다(Intel Iris Xe 기준).
4. **문장 조사 오류:** "머리은" → "머리는".
5. **광원 앞뒤 위치를 말하지 않음:** 1차 시도에서 S2 전등을 인물들 뒤 벽에 그렸습니다. 지시문이 화면 좌표만 주고 앞뒤 관계는 말하지 않았기 때문입니다. 이제 지시문에 다음을 적습니다.
   - 광원의 카메라 거리와 높이
   - 인물들보다 앞/사이/뒤인지 (예: "모든 인물보다 카메라 쪽 앞에 있음 — 인물들 뒤나 배경에 두지 말 것")

   pose.png에도 광원을 표시합니다. 화면 안이면 노란 해 모양, 화면 밖이거나 카메라 뒤면 가장자리에서 들어오는 노란 화살표입니다. 해는 실제 방향으로 멀리 투영해서, 화면 안에 들어오면 그 자리에 그립니다.

다시 만들려면 (dev 서버가 3001에서 실행 중일 때):

```bash
.review-tools/node/node.exe scripts/llm-package-scenarios.mjs http://127.0.0.1:3001
```

## 준비

파일 위치는 `docs/review-evidence/2026-11-06-llm-package/<장면>/`입니다.

| 장면 | 확인하려는 것 | 화면 |
|---|---|---|
| **S1-holiday** | 무릎 꿇은 인물, 우산 소품, 낮은 앵글, 흐린 역광 | 16:9 |
| **S2-queue-lamp** | 전등 하나 앞에 줄 선 4명: 거리별 밝기 차이, 앞사람 그림자 | 16:9 |
| **S3-dinner-spot** | 펜던트 스포트 아래 마주 앉은 2명, 식탁에 가려진 몸, 원 밖 어둠 | 16:9 |
| **S4-backlight-vertical** | 노을 역광 뒷모습 2명, 오른팔로 가리킴 | 9:16 세로 |

각 폴더에 들어 있는 파일:
- `shot-….zip`: 패키지. 압축을 풀어 사용합니다.
- `control-color.png`, `control-prompt.txt`: 대조군용
- `prompt.txt`: zip 안의 것과 같은 내용입니다. 복사하기 편하라고 꺼내 두었습니다.
- `contact-sheet.png`: 패키지 이미지를 한눈에 보는 용도입니다. 모델에는 넣지 않습니다.

## 실행 순서 (한 장면, 한 모델 기준)

매번 **새 대화**에서 시작하세요. 이전 결과가 섞이면 비교가 안 됩니다.

**B · 대조군을 먼저 합니다.** 패키지 내용을 본 뒤에 하면 판단이 흔들릴 수 있습니다.
1. 새 대화를 열고 `control-color.png`를 첨부합니다.
2. `control-prompt.txt` 내용을 그대로 붙여 넣고 보냅니다.
3. 결과를 `<장면>-<모델>-B.png`로 저장합니다. 예: `S2-gpt-B.png`

**A · 패키지**
1. 새 대화를 열고 zip을 풉니다.
2. `color.png`, `label.png`, `depth.png`, `light.png`, `pose.png` 5장을 첨부합니다.
   - 모델이 파일 첨부를 지원하면 `shot.json`도 같이 넣어도 됩니다. 필수는 아닙니다.
   - `depth16.png`는 넣지 마세요. 사람 눈에는 거의 검게 보이는 수치 파일이라 오히려 헷갈립니다.
3. `prompt.txt` 내용을 그대로 붙여 넣고 보냅니다.
4. 결과를 `<장면>-<모델>-A.png`로 저장합니다.

공통 규칙:
- 결과가 마음에 안 들어도 **다시 생성하지 말고 첫 결과로 채점**합니다. 조건마다 시도 횟수가 같아야 공정합니다.
- 모델이 "이미지가 너무 많다"며 거부하면, `color.png`·`label.png`·`light.png`·`pose.png` 4장으로 다시 하고 채점표에 적어 주세요.

## 채점

항목마다 **2 = 맞음, 1 = 애매하거나 일부만 맞음, 0 = 틀림**으로 매깁니다.

**공통 (모든 장면)**
- C1 인원수가 맞다.
- C2 화면 좌우 배치 순서가 맞다.
- C3 앞뒤 관계가 맞다(가까운 사람이 크고 앞에 있다).
- C4 카메라 높이·앵글이 맞다(올려다봄/내려다봄/눈높이).
- C5 누가 누구인지 맞다. 인물 설명(옷 색 등)이 올바른 위치의 인물에 입혀졌는지 봅니다.
- C6 라벨 색, 뼈대 선, 글자, 마네킹 질감이 그림에 새어 나오지 않았다.

**S1 · 홀리데이 우산**
- S1-a 앞쪽 인물(우산 든 사람)이 **자기 오른손**으로 우산을 들고 있다.
- S1-b 그 앞의 인물이 무릎을 꿇고 카메라에 **등을 보인다**.
- S1-c 낮은 앵글로 우산 든 사람을 올려다보는 위압감이 있다.
- S1-d 뒤쪽 좌우에 다른 두 사람이 서 있다.
- S1-e 빛이 뒤쪽 위에서 와서 카메라를 향한 얼굴·몸 쪽이 어둡고 윤곽이 밝다.

**S2 · 전등 앞 줄**
- S2-a 맨 앞(노란 우비)이 가장 밝고, 뒤로 갈수록 점점 어두워진다.
- S2-b 뒷사람의 몸 일부가 바로 앞사람의 그림자에 들어가 있다.
- S2-c 그림자가 전등 반대쪽으로 퍼져 바닥에 떨어진다.
- S2-d 전등(가로등)이 화면 왼쪽(가로 약 14%, 세로 약 32%)에 있고, **맨 앞 사람보다 카메라 쪽 앞**에 서 있다. 인물들 뒤나 벽에 있으면 0점입니다.
- S2-e 네 사람의 옷 설명이 줄 순서대로 맞게 입혀졌다.

**S3 · 식탁 스포트**
- S3-a 두 사람 모두 앉아 있다.
- S3-b 녹색 니트 남자가 **오른팔**을 식탁 위로 뻗고 있다.
- S3-c 흰 셔츠 여자의 아래쪽 몸이 식탁에 가려진다.
- S3-d 식탁 주변만 밝고 바깥(벽·방 구석)은 어둡다. 원뿔 모양의 빛 경계가 있다.
- S3-e 식탁 위에 머그컵이 있다.

**S4 · 노을 역광 (세로)**
- S4-a 세로 구도다.
- S4-b 두 사람 모두 **뒷모습**이다.
- S4-c 화면 왼쪽 사람이 **오른팔**로 가리킨다(뒷모습이므로 팔이 화면 오른쪽으로 뻗음).
- S4-d 역광 실루엣이다. 몸이 어둡고 윤곽이 밝다.
- S4-e 그림자가 카메라 쪽으로 길게 떨어진다.

**채점표 (복사해서 쓰세요)**
