# E2-depth-heights 채점 질문 (모두 "예"가 정답)

1. 아이가 어른보다 카메라에 가깝게(앞에) 서 있는가

4. 두 사람 사이에 몇 미터 이상의 거리가 느껴지는가
5. 두 사람을 같은 거리에 나란히 선 것처럼 그리지 않았는가
