# 광원 표시 유출 비교 (C1 장면, 나노바나나, 2026-11-11)

## 무엇을 비교했나

C1 장면(새벽 공원, 해가 카메라 뒤 위쪽)에서 하늘·화면 위에 빛무리가 그려지는 문제를 비교했습니다. 앞선 검증에서 2/2로 나왔습니다.

| 조건 | pose.png | 지시문 |
|---|---|---|
| 01 = 현재 | 노란 화살표 + "빛 방향 (카메라 뒤에서)" 글자 | 그대로 |
| 02 = 표시 없음 | 노란 표시를 지움 (`make-nomarker.mjs`) | 노란 표시 언급 3곳 삭제 |
| 03 = 화면 밖 문장 | 01과 같음 | 01 + "광원은 화면 밖에 있으니 해·전등·빛무리를 화면에 그리지 마세요." |

- 01은 앞선 검증의 이미지 2장을 그대로 썼습니다(같은 패키지).
- 02와 03은 각각 3회 생성했습니다.

## 판정

1. **빛무리는 노란 표시에서 오는 것이 아닙니다.**
   - 표시를 지워도 2/3에서 나왔습니다(현재 2/2).
   - "그리지 마세요" 문장을 넣어도 3/3에서 나왔습니다.
2. 빛무리는 장면 자체를 읽은 결과로 보입니다. color.png의 어두운 배경(벽이 없는 방의 빈 공간)과 "새벽", "빛은 화면 가운데 위"가 함께 있으면, 위쪽에서 비추는 빛을 하늘의 빛으로 그립니다.
3. 노란 화살표 자체가 그려진 경우는 지금까지 약 30장 중 2장입니다(G1 02_2, H1 01_2). 표시를 지우면 막을 수 있습니다. 하지만 지시문과 pose.png에서 빛 방향 정보가 빠지므로, 이 빈도로는 바꾸지 않습니다.
4. **결론:** 패키지 기본값(노란 표시, 지시문)은 그대로 둡니다.
