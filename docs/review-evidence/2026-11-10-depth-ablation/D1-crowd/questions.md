# D1-crowd 채점 질문 (모두 "예"가 정답)

1. 다섯 사람이 모두 그려졌는가
2. 왼쪽부터 빨강 코트 → 회색 후드 → 초록 점퍼 → 검은 정장 → 흰 원피스 순서인가(화면 가로 위치)
3. 빨간 코트 여자가 가장 앞(가장 아래쪽 발)인가
4. 흰 원피스 여자가 가장 뒤(가장 위쪽 발)인가
5. 측정: 초록 점퍼 소년 ÷ 검은 정장 남자의 화면 키 비율
6. 측정: 빨간 코트 여자 ÷ 흰 원피스 여자의 화면 키 비율
