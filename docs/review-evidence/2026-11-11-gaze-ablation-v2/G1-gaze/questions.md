# G1-gaze 채점 질문 (모두 "예"가 정답)

1. 두 사람이 모두 그려졌는가
2. 남자(왼쪽)의 얼굴·눈이 여자를 향하는가(카메라를 보면 아니오)
3. 여자(오른쪽)의 얼굴·눈이 남자를 향하는가(카메라를 보면 아니오)
4. 남자의 표정이 걱정스러운가(참고: 지시문에 표정이 있는 조건만 해당)
5. 여자의 표정이 옅은 미소인가(참고: 지시문에 표정이 있는 조건만 해당)
6. 좌우 배치가 맞는가(남자 왼쪽, 여자 오른쪽)
