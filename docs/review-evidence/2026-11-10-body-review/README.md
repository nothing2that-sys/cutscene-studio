# 체형 확인용 이미지 (2026-11-10)

체형 다양화 1단계의 통과 기준은 "사용자가 보고 체형 차이가 읽힌다고 판단"입니다. 아래 이미지를 보고 판단해 주세요.

## 01–06 · 체형 5종 비교

- 왼쪽부터 순서대로 놓았습니다.
  1. 성인 여성(기존)
  2. 성인 남성
  3. 중성
  4. 아이(약 5.5등신)
  5. 큰 체격 남성
- 모두 같은 휴식 자세이고, 실제 키 비율대로 놓았습니다.
- 05·06은 검은 실루엣입니다. 이미지 생성 모델이 윤곽만으로 체형을 읽는지 볼 때 씁니다.

**판단할 것**
- 남성·중성이 여성과 구분되는가
  - 가슴, 골반, 허벅지 윤곽을 봐 주세요.
  - 남성과 중성의 허벅지가 아직 넓어 보일 수 있습니다.
- 아이가 "작은 어른"이 아니라 아이로 읽히는가
  - 머리 비율과 팔다리 길이를 봐 주세요.
- 큰 체격 남성이 "뚱뚱한 남성"으로 읽히는가
