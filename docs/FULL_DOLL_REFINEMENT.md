## 비례와 손발

원본을 옆에 두고 좁았던 흉곽·가슴, 짧았던 머리 턱 부분, 치우친 골반과 어깨 간격을 조정했다. 아래 수치는 설계 좌표의 변화이며 원본 외곽 오차를 자동 측정한 값은 아니다. 단일 그림에서 깊이와 후면을 복원했다고 주장하지 않는다.

- 머리 최대 반폭 53 → 57, 턱 끝을 아래로 연장하고 중간 단면을 보강.
- 흉곽 주요 반폭 86 → 100, 가슴 돌출 52 → 60, 좌우 간격 42 → 46. 뒤·옆 흉곽은 별도 폭 계수 .88로 팔과 간섭하지 않게 축소.
- 어깨 중심 간격 182 → 200. 원본 비교 자세에서는 몸통 회전으로 투영 폭을 맞추고 골반의 좌측 이동을 줄였다.
- 팔·다리의 연결 길이는 유지했다. 원본 자세의 깊이 방향과 허리 회전을 다시 배분해 머리–손, 몸통–손이 뚫리지 않게 보정했다.
- 손바닥은 엄지 쪽 살집과 손가락 뿌리 단면을 추가했다. 손가락별 길이, 끝마디, 엄지 각도, 손톱을 조정했다.
- 발은 안쪽 아치와 평평한 밑면, 뒤꿈치·발등·앞볼의 연결을 보완했다. 발가락 길이 차이와 끝부분·발톱도 실제 메시다.
- 손가락 마디와 손발톱은 손·발마다 하나의 표시 메시로 합친다. 작은 끝부분의 분할 수를 줄여 전신의 면 수 증가를 억제했다.

## 관절 접촉

새 `doll-contact.js`는 화면에 쓰는 삼각형을 BVH로 검사한다. 닫힌 구성 요소별 내부 판정을 합집합으로 취급하고 다른 부품의 표면 정점이 그 내부에 들어갔는지 확인한다. 관절 중심 주변의 연결부와 허리 안쪽 끼움 영역만 의도된 맞물림으로 허용한다. 이 허용 영역은 이전/이후 비교에서 동일하다. 외피를 숨기거나 뼈 길이를 줄이는 방식은 쓰지 않는다.

- 어깨·고관절 연결구를 소켓의 가장 작은 반경 안에 맞는 구로 변경했다. 위팔 안쪽을 좁히고 허리 소켓 여유를 조정했다.
- 관통 방지는 기본으로 켜진다. 관절 입력을 최대 5도 간격으로 검사하고, 처음 접촉하는 구간에서 이분 탐색한 뒤 .75도 여유를 둔다. 최종 각도는 전체 정점으로 다시 확인한다. 요청 각도와 실제 적용 각도를 화면에 표시한다.
- 검사 범위는 움직이는 관절의 자손 부품과 다른 전신 부품이다. 손발가락 굽힘도 손·발과 다른 부품의 접촉으로 제한한다.
- 기본 자세와 불러온 자세는 접촉을 줄이는 작은 회전 보정을 적용한다. 해결하지 못한 겹침은 화면에 남은 개수와 깊이를 표시한다.
- 관통 방지를 끄면 제한 전 형상·자세를 비교할 수 있다. 큰 굽힘에 필요한 어깨·손목 방향은 사용자가 먼저 잡을 수 있다.

[limits.json](review-evidence/2026-11-03-full-refinement/limits.json)은 같은 최신 메시에서 보호 OFF/ON을 비교한다. 예를 들어 중립에서 팔꿈치만 접으면 손이 허벅지에 먼저 닿으므로 약 18도에서 멈춘다. 이것을 팔꿈치의 해부학적 가동 범위라고 해석하면 안 된다. 무릎 약 95도, 고관절 약 -77도, 허리 비틀기 약 12도 역시 검사 시작 자세에서의 접촉 한계다. 제한을 무시한 최대 굽힘을 유지하도록 외피를 변형하는 기능은 없다.

## 확인 결과와 한계

[접촉 검사](review-evidence/2026-11-03-full-refinement/after-contacts.json): 원본 비교·중립·쪼그림·양팔 올림·걸음, 팔꿈치·무릎·고관절 최대 요청·팔 가로지르기·허리 비틀기의 좌우와 양방향을 포함한 15개 결과에서 허용 결합부를 제외한 외피 정점 침투 0개를 확인했다. 외부 검사에서는 모든 정점을 검사했고 .006 보기 단위(원본 좌표 약 1.2px)보다 깊은 침투를 집계했다. 실시간 탐색은 4정점 간격과 약 .6px 기준을 사용하고, 최종 적용 전에는 모든 정점으로 재검사한다. 작은 겹침이 남으면 .5도씩 물려 안전한 각도를 적용한다. 이전 자료의 정점 간격은 8이므로 이전/이후 개수의 감소율을 비교하지 않는다.

삼각형 교차 전체를 연속 시간으로 증명하는 물리 엔진은 아니다. 정점이 내부에 없는 얇은 삼각형 교차, 같은 손 안의 손가락끼리의 접촉, 바닥·외부 물체의 접촉·균형은 처리하지 않는다. 깊이는 표시 삼각형까지의 거리이며 구성 요소가 겹치는 내부 경계에서는 합집합의 정확한 부호 거리와 다를 수 있다. 모든 사용자 자세에서 무관통을 보장하지 않는다.

[전신 흐름 검사](review-evidence/2026-11-03-full-refinement/flow/checks.json): 브라우저 오류 0, 유한 좌표, 연결 길이 최대 오차 6.7×10⁻¹⁶ 보기 단위, 저장 왕복·Undo/Redo·잘못된 굽힘축 입력의 원자적 거부를 확인했다. 고정 앵글의 팬·줌·XYZ 이동은 추가 WebGL 렌더 0회다. [기존 몸통 회귀 검사](review-evidence/2026-11-03-full-refinement/core-regression/checks.json)도 통과했다.

[부하 검사](review-evidence/2026-11-03-full-refinement/performance.json): 최종 **30,512 삼각형 / 17 draw calls**, 이전 30,416 대비 +96면(약 .3%)이다. 중간 관절 이동에서는 손의 로컬 메시 재계산을 생략하고, 손가락이 움직일 때만 갱신한다. 전신 전용 몸통 미리보기는 208,944바이트이며 초기 조형 계산을 생략한다. 로컬 Chrome 단일 측정의 준비 시간은 약 970ms였다. FPS나 다른 기기의 성능을 보장하는 수치는 아니다. 접촉 검사는 포즈 변경 때만 실행되며 고정 선화의 이동에는 실행되지 않는다.

원본의 유려한 실루엣·기울기와 손발 방향에는 차이가 남는다. 어깨·골반 경계와 큰 마디의 단순화도 비교 이미지에 보인다. 관절 위치 일치나 겹침 검사 통과를 원본 재현 합격으로 간주하지 않는다.
