# 전신 작화 인형 — 3D 포즈 / 2.5D 선화

2026-11-03. 실행: http://127.0.0.1:3001/doll-full.html

기존 중심 부품에 새 머리·목, 좌우 팔·손, 좌우 다리·발을 연결한 **실제로 움직이는 전신 시제품**이다. 앱 기본 인체는 교체하지 않았다. 기준 체형 1종이며, 외형의 최종 합격이나 충돌 없는 전 자세 동작을 선언하지 않는다.

## 사용 흐름

1. `3D 보기`에서 드래그로 앵글을 잡는다. 자세 목록에는 원본 비교, 중립, 두 팔 올림, 한 걸음, 쪼그림이 있다.
2. 오른쪽 관절 선택과 X/Y/Z 슬라이더로 포즈를 수정한다. 팔꿈치·무릎은 지정된 굽힘축만 열린다.
3. 손가락과 발가락의 굽힘도 각각 조절할 수 있다. 손·발의 보기 범위를 골라 확대 검토할 수 있다.
4. `조작 → 2.5D · 앵글 고정`을 선택하면 같은 앵글의 선화가 된다. 단색 면/현재 3D 음영과 관절·구조선 표시도 선택할 수 있다.
5. 고정 모드에서 드래그·휠·XYZ 이동은 이미지를 재사용한다. 형상/포즈/앵글이 바뀌면 투영을 갱신한다. 3D 복귀는 기존 고정 보기 기능과 같은 방식으로 팬/줌을 카메라에 옮긴다.
6. 현재 보기 PNG, 전신 포즈 JSON, 실제 전신 메시 OBJ를 저장할 수 있다. 포즈 편집의 되돌리기/다시 실행을 제공한다.

## 부품과 관절

| 부위 | 이번 구현 |
|---|---|
| 머리·목 | 턱이 좁아지는 별도 머리, 목 밑이 넓어지는 목 외피, 머리 회전 연결. 얼굴 중심선과 가로 방향선을 3D 표면에서 투영 |
| 흉곽·복부·골반 | 시제품 03의 경량 몸통과 실제 어깨/고관절 소켓을 재사용. 세 부품의 기존 강체 계층 유지 |
| 어깨·상완 | 소켓 중심에 어깨 연결부를 배치하고 삼각근 쪽에서 팔꿈치로 좁아지는 별도 외피 연결 |
| 팔꿈치·전완 | 원형 회전부를 사이에 둔 별도 상완/전완. 좌우 반대 방향의 단일 굽힘축, 비대칭 전완 단면 |
| 손목·손 | 손목 연결, 납작한 손바닥, 엄지 분기와 각 손가락 마디. 단순 손 이미지가 아니라 실제 3D 손 |
| 고관절·허벅지 | 골반 소켓에 맞춘 고관절 연결부와 테이퍼·앞뒤 깊이가 다른 허벅지 |
| 무릎·종아리 | 실제 무릎 위치의 굽힘 연결부, 종아리 뒤 볼륨·가는 발목을 가진 별도 외피. 피부 위에 별도 무릎 뚜껑을 붙이는 구조는 사용하지 않음 |
| 발목·발 | 발목 연결, 뒤꿈치·아치·발등·앞꿈치와 길이가 다른 발가락. 발가락도 마디를 따라 굽힘 |

선택 가능한 주요 관절은 17개다. 손가락·발가락 마디와 끝점을 포함하면 85개의 계층 노드가 있다. 이 숫자에는 끝점 노드가 포함되며 85개의 독립 기계 관절을 뜻하지 않는다.

팔꿈치는 국소 Z축, 무릎은 국소 X축으로 굽힌다. 전신 포즈 JSON에서도 이 굽힘축과 범위를 검사하며 잘못된 포즈 파일은 기존 상태를 바꾸지 않고 거부한다. 다른 관절의 슬라이더 범위는 디지털 시제품 편집 범위이며 의학적 가동범위나 제조 기구의 제한을 인증한 값은 아니다.

손가락·발가락은 마디별 강체 변환을 계산해 각 손/발의 하나의 표시 메시로 묶는다. 따라서 마디마다 draw call을 늘리지 않으면서 실제 굽힘을 표시한다. 동작은 단순 2D 변형이 아니다. 각 부품의 형상은 명시적인 단면 데이터와 저해상도 연결부 메시로 작성했으며, 이전 `body-study-cage.js`의 팔다리를 잘라 재사용하지 않았다.

## 원본 비교 자세

원본과 같은 960×1280 프레임에 해당하는 정사영을 사용한다. 몸통 프리셋을 유지한 상태에서 어깨 → 팔꿈치 → 손목, 고관절 → 무릎 → 발목의 위치를 맞춘다. 각 뼈는 고정 길이를 유지하며, 원본에서 알 수 없는 깊이 방향을 선택해 화면상 목표에 도달하도록 강체 회전한다. 손바닥 방향·손가락 굽힘·발목 각도·발가락도 별도로 포즈를 잡았다.

[reference-anchors.json](review-evidence/2026-11-03-full-doll/reference-anchors.json)에 원본 판독 좌표와 실제 투영 좌표를 기록했다. 팔꿈치/손목/무릎/발목이 목표에 놓이는 것은 이 좌표를 제작에 사용했기 때문이며, 외형 유사성을 독립 검증한 수치가 아니다. 가려진 고관절 중심은 추정이고 기존 골반 소켓 중심과 원본 판독치 사이에 약 10~14px 차이가 남는다. 손발 접촉, 숨은 면, 카메라와 깊이는 한 장의 선화에서 확정할 수 없다.

모든 모델 이미지는 실제 Chrome/WebGL 실행 결과다. 생성형 이미지를 구현 증거로 사용하지 않았다. 합본은 원본과 캡처를 크기 맞춰 나란히 붙인 자료다. 상세 보기들은 각각 확대했으므로 그 이미지끼리 크기 비례를 비교하지 않는다.

첫 전신 선화에서는 작은 둥근 손가락/발가락의 정상적인 법선 변화가 모두 검은 선으로 잡혔다. 단순 법선 차이뿐 아니라 양쪽 변화의 불연속도 함께 검사하도록 공용 선 추출을 보완했다. 발가락 시작부도 앞꿈치 안쪽으로 옮겨 연결을 보완했다. 외곽/관절 구조선과 실제 형태는 별개로 계속 확인한다.

## 부하와 확인

전신 기본 표시는 **30,416 삼각형, 17 draw calls**다. 중립/원본/다른 포즈에서 부품 메시를 늘여 뼈 길이를 바꾸지 않는다. 원래의 몸통만 있는 11,600면 시제품보다 부품이 늘었으므로 그리기 비용이 같다고 주장하지 않는다. 고정 앵글의 전신 이동·확대·XYZ 이동은 확인된 시나리오에서 WebGL 재렌더 0회였다. 선화 투영을 새로 만들 때는 별도의 렌더/선 추출 비용이 발생한다. 저사양 PC의 FPS 실측은 하지 않았다.

[checks.json](review-evidence/2026-11-03-full-doll/checks.json)의 검증 범위:

- 실제 3D/2.5D 실행, 전신/손발 상세 캡처, 브라우저 오류 없음.
- 원본 비교·중립·팔 올림·걸음·쪼그림의 모든 연결 길이 유지. 관찰된 최대 수치 드리프트 약 4.4×10⁻¹⁶ 보기 단위.
- 팔꿈치 비굽힘축 비활성화 및 슬라이더 범위 제한.
- 포즈 JSON 저장 상태의 왕복 복원, 되돌리기/다시 실행.
- 잘못된 팔꿈치 축의 포즈를 기존 상태 변경 없이 거부.
- 고정 모드에서 이미지 재사용과 WebGL 추가 그리기 0회.

공용 선화 추출을 바꾼 뒤 기존 몸통의 [고정 보기 회귀 검사](review-evidence/2026-11-03-full-doll/core-fixed-regression/checks.json)도 수행했다.

- 전신 형상/관절: `app/src/doll-full-rig.js`
- 전신 편집 화면: `app/doll-full.html`, `app/src/doll-full.js`
- 고정 투영: 기존 공용 `app/src/doll-fixed-view.js`

포즈 JSON은 `articulated-full-doll-pose` 형식으로 이 전신 시제품에서 다시 연다. 기존 앱의 포즈 JSON이라고 주장하지 않는다. OBJ는 현재 자세의 정적 메시이며 리그/포즈 편집 원본은 아니다. 보기 범위를 손/발로 좁혀도 OBJ는 전신을 내보낸다. 현재 보기 PNG는 화면 범위·고정 보기의 팬/줌을 반영한다. 조형 단위는 원본 픽셀 비례 기준이며 키(cm)·등신·체형 확장은 아직 적용하지 않았다.

기존 앱의 고정 뼈 길이·관절 제한·저장 포즈/JSON·Undo/Redo·캡처·전달 묶음 코드는 변경하지 않았다. 이 전신 시제품은 별도 비교 화면이며 기본 인체 자동 교체는 하지 않는다.

## 남은 외형/동작 차이

- 원본과 가슴 외곽·몸통/골반 비례·머리 윤곽·손발의 세부 모양 차이가 남는다. 관절점 일치를 외형 합격으로 삼지 않는다.
- 후면과 깊이, 관절의 내부 구조는 설계 추정이다. 연결부는 디지털 인형이며 제조 가능한 구체관절 기구로 검증하지 않았다.
- 어깨/고관절과 외피의 경계·노출 정도, 목/손목/발목 연결은 추가 조형 검토가 필요하다.
- 극단 자세의 자기 관통, 손의 몸통/머리 접촉, 발의 바닥 접촉과 균형은 자동 보정하지 않는다. 손목의 복잡한 포즈와 쪼그림에서도 간섭이 남을 수 있다.
- 손발은 마디가 있는 단순화된 작화 인형이다. 작은 부위는 전신 선화에서 짙어지거나 생략되어 보일 수 있고 상세 확대에서는 저해상도 단면이 보인다.
- 고정 모드는 전신 전체 한 레이어다. 다른 인물/물체 또는 독립 부품과의 새 가림 관계는 깊이 합성이나 재투영으로 확장해야 한다.
