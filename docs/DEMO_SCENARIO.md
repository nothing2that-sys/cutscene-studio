# 사용 영상 시나리오

대상: 처음 사용하는 소설가·작화가. 16:9, 1920×1080, 약 1분 20초, 한국어 화면 자막, 무음. 실제 편집기를 녹화하고 마지막에 기존 작화 예제를 비교한다. 조작과 다운로드에 걸리는 시간에 따라 길이가 조금 달라진다.

핵심 메시지: 글로 설명하기 어려운 배치와 카메라를 직접 확인하고, 이미지 생성 도구에 전달한다.

| 구간 | 화면과 조작 | 전달할 내용 |
| --- | --- | --- |
| 00:00–00:05 | 편집기와 제목 | 소설에서 작화 참조까지 |
| 00:05–00:11 | 예제 장면 클릭 | 두 인물과 소품의 공간 배치 |
| 00:11–00:17 | 빗속 액션 JSON 열기 | 인물·조명·카메라를 한 번에 불러오기 |
| 00:17–00:23 | 작업 화면 드래그 | 여러 방향에서 배치 확인 |
| 00:23–00:28 | 컷 이름 입력, 구도 저장 | 작업 시점과 촬영 컷 구분 |
| 00:28–00:33 | 원래 장면 재로드, PNG 캡처 | 가이드 없는 참조 내보내기 |
| 00:33–00:40 | LLM 패키지 ZIP 다운로드 | 컬러·라벨·깊이·조명·포즈와 설명 전달 |
| 00:40–00:49 | 참조와 기존 최종 작화 나란히 | 외부 이미지 생성 결과와 차이 확인 |
| 00:49–00:54 | 저장소 주소, 마무리 | 직접 실행하고 예제 다운로드 |

위 시간은 자막 유지 시간 기준이며 실제 로딩·내보내기 시간이 추가된다. 최종 타이밍은 [녹화 보고서](demo/recording-report.json)의 `cues`에 기록된다.

최종 작화는 기존 image_gen 결과다. 영상 촬영 중 AI를 호출하지 않는다. 정확한 포즈·조명·구도 재현을 보장하거나 편집기에 자동 작화 기능이 있는 것처럼 표현하지 않는다. 인물·의상·조명은 장면 전환 전까지 유지하고, 참조 비교 화면에서만 3D와 작화의 차이를 명시한다.

재녹화: 로컬 서버 실행 후 `node scripts/record-demo.mjs`. Playwright와 Chrome, `node .review-tools/node_modules/playwright/cli.js install ffmpeg`가 필요하다. 결과는 `docs/demo/cutscene-studio-demo.webm`이다.
