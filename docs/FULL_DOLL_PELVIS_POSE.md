# 골반 회전과 앞뒤 발 배치 수정

2026-11-03. [전신 화면](http://127.0.0.1:3001/doll-full.html)

[정면과 사선 비교](review-evidence/2026-11-03-pelvis-pose/pelvis-comparison.png) · [측면 비교](review-evidence/2026-11-03-pelvis-pose/stance-side.png)

이전 원본 비교 자세는 흉곽이 약 34도 돌아갔지만 골반은 0도였다. 다리는 각각 2D 관절점과 깊이 부호를 선택해 배치했고, 실제로는 그림 기준 오른발이 왼발보다 카메라 뒤에 있었다. 정면 관절점·외곽의 유사성이 몸통과 다리의 일관된 3D 방향을 뜻하지 않는다는 점을 놓쳤다.

현재 골반은 Y 회전 32도, 복부의 세계 방향은 약 30도, 흉곽은 약 34도다. 골반의 고관절 간격과 소켓·외피 폭도 3D 기준으로 함께 조정했다. 좌우 고관절의 중립 간격은 122→146 설계 좌표 단위다. 골반을 회전해도 정면 간격을 유지하려고 뼈를 포즈마다 늘이는 방식은 쓰지 않는다. 고관절 좌표는 소켓 설계와 같은 값을 사용한다.

두 발을 먼저 실제 3D 위치에 두고, 고정 길이 두 뼈 IK와 몸의 앞 방향을 기준으로 무릎을 계산한다. 그림 기준 오른발은 앞, 왼발은 뒤다. 발끝도 골반 방향을 따르되 뒤쪽 발은 약간 바깥으로 돌렸다. 오른쪽 발목의 과한 굽힘은 줄였고, 뒤로 빠지는 왼 고관절 접합부의 뒤쪽 외피를 다듬었다. 골반 회전에 따라 왼손이 몸통 안으로 들어가지 않도록 손목의 깊이 해도 바꿨다.

[수정 전](review-evidence/2026-11-03-pelvis-pose/before-pose.json)과 [수정 후](review-evidence/2026-11-03-pelvis-pose/after-pose.json)의 실제 좌표를 기록했다.

| 측정 | 이전 | 현재 |
| --- | ---: | ---: |
| 골반의 세계 앞 방향 | 0도 | 약 31.9도 |
| 복부의 세계 앞 방향 | 약 11.8도 | 약 29.5도 |
| 흉곽의 세계 앞 방향 | 약 34.3도 | 약 34.3도 |
| 오른발−왼발의 카메라 Z | −.159 | +1.225 |
| 오른발−왼발의 골반 앞 방향 성분 | −.159 | +1.748 |

양수는 오른발이 앞이라는 뜻이다. 좌표 단위는 설계 픽셀/200이며 cm가 아니다. 32도와 깊이는 단일 원본에서 복원한 유일한 정답이 아니라, 사용자가 지정한 측면 방향과 오른발 앞/왼발 뒤의 관계를 만족시키는 설계값이다. 발목의 정면 위치는 유지하지만 무릎은 실제 굽힘 방향을 따라 다시 계산하므로 이전의 화면 목표점과 완전히 같지 않다. 이 단계의 목표는 3D 포즈의 방향을 일관되게 만드는 것이다. 바닥 접지·균형과 족부 생체역학을 검증한 것은 아니다.

## 확인

- `scripts/doll-pelvis-review.mjs after`: 골반 방향 25–40도, 골반/흉곽 방향 차이 8도 이내, 오른발의 카메라 깊이와 몸 앞 방향 성분이 모두 앞, 자동 접촉 보정 없음, 1.2px 기준 외피 정점 침투 없음. 정면·측면·사선과 고정 선화를 실제 모델에서 캡처했다. 파란색은 그림 기준 오른다리, 황토색은 왼다리이며 색과 글자는 비교용이다.
- [전신 흐름](review-evidence/2026-11-03-pelvis-pose/flow/checks.json): 연결 길이 유지, 저장 왕복·Undo/Redo, 잘못된 굽힘축 입력 거부, 브라우저 오류 없음, 고정 모드 이동·확대·XYZ 추가 WebGL 렌더 0회. 28,720면/15회 그리기는 유지했다.
- [접촉 15종](review-evidence/2026-11-03-pelvis-pose/contacts/after-contacts.json): 기본 자세 5종과 좌우 큰 굽힘 10종에서 허용 결합부를 제외한 1.2px 이상 정점 침투 0개. 더 엄격한 0.6px 기준의 [원본 자세 진단](review-evidence/2026-11-03-pelvis-pose/raw-diagnostic.json)에서는 왼 고관절 연결 근처에 약 .86px 침투 정점 1개가 남는다. 무관통을 연속 시간의 모든 삼각형 교차까지 보장하는 물리 검증은 아니다.
- 인물 설명 저장/복원과 메인 작화 전달도 새 리그에서 재확인했다. 손발 세부를 인물 설명으로 넘기는 원칙은 유지한다.

```powershell
.review-tools/node/node.exe scripts/build-doll-full-preview.mjs
.review-tools/node/node.exe .review-tools/node/node_modules/npm/bin/npm-cli.js --prefix app run build
.review-tools/node/node.exe scripts/doll-pelvis-review.mjs after
powershell -ExecutionPolicy Bypass -File scripts/doll-pelvis-sheets.ps1
```

`before` 캡처는 당시 메시와 코드의 기록이므로 현재 코드로 다시 덮어쓰지 않는다. 이전 실루엣 IoU와 정점 일치 수치는 이전 포즈에 대한 기록이며 새 3D 자세의 정확도 점수로 재사용하지 않는다.
