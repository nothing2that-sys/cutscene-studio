# 공개본 준비와 검증

준비일: 2026-11-11. 대상: `nothing2that-sys/cutscene-studio`.

공개 사본은 현행 앱·예제·개발 문서·선별한 생성 실험 원본을 포함한다. 과거 Git 이력, 개인 첨부·세션 파일, 외부 원본 포즈 이미지, 재배포 대상에서 제외한 포즈 보정 데이터, 대형 개인 작업 프로젝트는 포함하지 않는다. 개인 로컬 사용자 경로·연락처·내부 주소·개인 Drive 링크는 일반 문자열로 치환했다. 원본 작업 폴더와 기존 비공개 저장소 이력은 보존한다.

공개 사본 자체에서 확인한 결과:

- `npm --prefix app ci`: 성공, 설치 시점 취약점 보고 0건.
- `npm --prefix app run build`: 성공, 108개 모듈. 일부 번들 500 kB 초과 경고는 남아 있다.
- `node --test scripts/*.test.mjs`: 52개 통과.
- 실제 편집기 사용 영상: 1920×1080, 25 fps, 80.76초, 한국어 자막, 무음.
- 장면 불러오기·작업 시점 이동·구도 저장·컬러 PNG·LLM ZIP 다운로드를 실제 녹화, 페이지 예외 0건.
- [녹화 보고서](demo/recording-report.json), [갤러리](EXAMPLE_GALLERY.md), [시나리오](DEMO_SCENARIO.md).

이번 공개 준비에서 전체 브라우저 회귀 검사를 다시 실행하지는 않았다. 과거 검증 결과는 해당 날짜의 개발 문서를 참고한다.
