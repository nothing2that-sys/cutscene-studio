# 인물 이동·직접 포즈 조작·내 포즈

편집기를 새로고침하면 **인물 이동**이 기본입니다. 기존 관절 수치와 기즈모는 **세부 조정**으로 옮겼습니다.

**포즈 잡기**는 선택 인물만 보이는 단독 화면이 기본입니다. **인물 이동**으로 나가면 전체 장면과 이전 카메라가 돌아옵니다. **가벼운 화면**은 편집 부하만 줄이며 최종 PNG는 전체 장면·기존 품질을 유지합니다. [성능 설정](PERFORMANCE.md).

Drive 자료는 **이미지 레퍼런스**에서 검색합니다. 변환 카드를 고르면 선택 인물에 추정 3D 자세를 적용하고, 편집 시점만 인물 전체에 맞춥니다. 품질 필터에서 보정 필요 항목을 구분하고 원본과 비교해 고친 결과를 내 포즈에 저장하세요. [이미지 자료 사용법과 다른 PC 등록](IMAGE_REFERENCES.md).

## 인물을 통째로 이동

**인물 이동**에서 몸의 어느 부분이든 잡아 끌면 선택한 인물 전체가 움직입니다. 좌우 드래그는 화면의 좌우 방향, 위아래 드래그는 바닥의 앞뒤 방향입니다. **Shift를 누르고 드래그하면 높이**를 바꿉니다. 빈 곳은 기존처럼 화면 회전에 사용합니다. 인물 내부의 뼈 길이·자세는 바꾸지 않습니다. 소품도 같은 방식으로 옮길 수 있습니다.

## 무릎·발목 등을 직접 잡기

**포즈 잡기**를 누르면 선택 인물에 머리·허리·팔꿈치·손목·무릎·발목의 이름 붙은 원이 표시됩니다. 파랑은 인물의 왼쪽, 주황은 오른쪽입니다.

- 무릎을 끌면 무릎 자체가 이동하고 아래 다리와 발목이 따라갑니다.
- 발목을 끌면 허벅지·무릎 회전으로 목표에 접근합니다. 곧게 편 다리의 발목을 몸 쪽으로 당겨도 무릎이 굽혀집니다.
- 손목은 팔·팔꿈치, 팔꿈치는 위팔을 사용합니다. 표시한 점과 조작 대상이 일치합니다.
- 목표는 화면과 평행한 평면에서 움직입니다. 앞뒤가 필요하면 **정면·옆면·위** 보기를 바꿔 조작하세요.
- 점이 겹치면 클릭 위치를 벌리고 실제 관절까지 점선으로 연결합니다. 노란 목표 원과 실제 관절의 차이로 닿지 않는 위치를 확인할 수 있습니다.
- Escape는 진행 중인 드래그를 취소합니다. 드래그 한 번은 Undo 한 번으로 되돌립니다.

관절 범위와 길이 고정은 유지합니다. 골반·발 접지·충돌·균형을 함께 푸는 전신 물리 제어는 아닙니다. 다리가 닿지 않는 목표에는 뼈를 늘리지 않습니다. 작업 시점이 방 벽 바깥에 있으면 그 벽을 작업 화면에서 걷어 보여줍니다. 저장 컷·미리보기·최종 PNG는 원래 벽을 유지합니다.

## 저장된 참조 포즈 적용

인물을 고르고 **내 포즈**에서 카드를 누르거나 **포즈 JSON 불러오기**를 사용하세요. 새 인물을 추가하지 않고 선택한 인물의 관절만 바꿉니다. 키·등신·가슴 형태·뼈 길이·인물 이름·수평 배치는 유지합니다. **발 높이 유지**가 켜져 있으면 자세에 따른 Y 높이만 보정합니다.

앱에서 저장한 `pose-reference` JSON, 개별 인물 JSON, 프로젝트/전달 묶음, 장면 JSON을 받습니다. 파일에 여러 인물이 있으면 참조할 인물을 고르는 창을 표시합니다. 의미 관절 JSON은 예를 들어 다음과 같이 작성하며 각도는 기존 장면 포맷의 도 단위입니다.

```json
{"pose":"standing","joints":{"r_arm":{"raise":100},"r_elbow":{"bend":70}}}
```

앱이 내보내는 `type: pose-reference`의 `rotations`는 `rotationUnit: radians`인 정밀 회전 배열입니다. 위치·크기 데이터를 포즈로 복사하지 않습니다.

```powershell
node scripts/validate-pose.mjs examples/poses/wave.json
```

## 라이브러리 계속 쌓기

기본 참조 10개는 기존 `cutscene-studio`의 관절·접지 지침으로 직접 작성하고 실제 3D로 렌더링한 포즈입니다. 외부 갤러리 이미지를 복사한 자료가 아닙니다. [회전 JSON](../examples/poses/)과 앱의 미리보기를 제공합니다. 정확한 손 접촉·의자 면·균형은 장면에 맞춰 수정하세요.

**작업 포즈 자동 모음**이 기본으로 켜져 있습니다. 관절 자세가 바뀐 작업을 라이브러리에 기록하고 같은 자세는 중복 저장하지 않습니다. 인물 전체 이동·카메라 조작은 새 포즈로 기록하지 않습니다. **현재 포즈 담기**로 이름을 정리할 수 있고, 이미 자동 저장된 자세에는 입력한 이름을 붙입니다. **포즈 저장**은 선택 인물의 자세를 개별 JSON 파일로 내보냅니다.

최근 작업 포즈를 위쪽에 표시하며, **포즈 이름 검색**으로 저장한 자세를 찾을 수 있습니다. 필요 없는 포즈는 카드에서 삭제할 수 있습니다.

라이브러리는 서버나 GitHub가 아닌 **현재 브라우저의 IndexedDB**에 보관합니다. 같은 브라우저 프로필과 같은 접속 주소(`http://127.0.0.1:3001`)에서 새로고침·재시작 후 유지됩니다. 브라우저 데이터 삭제, 다른 프로필·주소·포트에서는 별도 저장소가 됩니다. 정기적으로 **라이브러리 백업**을 내려받아 로컬 파일로 보관하세요. **백업 가져오기**는 ID 기준으로 추가·갱신하며 기존의 다른 포즈를 삭제하지 않습니다. 현재 가져오기 한도는 50MB·2,000개입니다.

프로젝트 **Save**는 장면 저장이고 포즈 라이브러리 백업과는 별개입니다.

브라우저 저장소를 사용할 수 없으면 오류를 표시합니다. 이때 개별 **포즈 저장** 파일을 이용하세요. 작업을 매번 SVG·이미지 융합으로 다시 만들 필요 없이 기존 포즈를 적용한 뒤 필요한 관절만 고치면 됩니다.
