# 자료 효과 비교 실험 (한 번에 하나씩, 3회 반복)

## 왜 다시 하나

1차 비교에는 세 가지 문제가 있었습니다.
1. **조건마다 한 장씩이었습니다.** 같은 입력으로도 매번 다르게 나오므로, 자료 덕인지 운인지 구분할 수 없었습니다.
2. **자료를 한꺼번에 넣었습니다.** 효과가 있어도 어느 자료 덕인지 알 수 없었습니다.
3. **답을 미리 알려 줬습니다.** 장면 원문에 "화면 오른쪽 밖 랜턴", "아이가 앞, 어른이 뒤"처럼 정답이 적혀 있어서, 자료 없이도 맞힐 수 있었습니다.

이번에는 다음처럼 바꿉니다.
- **한 번에 하나만 추가합니다.**
- **조건마다 3번씩 생성합니다.**
- **장면 원문에서 위치와 거리를 뺐습니다.** 정답은 이미지 자료에만 있습니다.

## 조건

모든 조건의 지시문 맨 앞에는 같은 화풍 문장(2D 웹툰 일러스트, 실사·3D 금지)이 들어 있습니다.

| 조건 | 첨부 이미지 | 지시문에 추가되는 것 |
|---|---|---|
| **c1-color** | color.png | 장면 원문, 인물 외형만 |
| **c2-text** | color.png | + 카메라 정보, 인물별 화면 위치·포즈 문장 |
| **c3-light** | color.png, light.png | + c2 + 조명 설명 (광원 종류·위치·앞뒤 관계, 인물별 명암) |
| **c4-depth** | color.png, depth.png | + c2 + 거리 설명 (카메라에서 가까운 순서, 인물별 거리) |

비교하는 방법:
- c1과 c2의 차이 = 설명 문장의 효과
- c2와 c3(또는 c4)의 차이 = 조명(또는 뎁스) 자료의 효과

## 장면

| 장면 | 확인하는 것 | 조건 |
|---|---|---|
| **E1-under-light** | 바닥 가까이 놓인 화면 밖 랜턴. 얼굴 아래쪽이 밝고, 뒤 벽에 그림자가 크게 위로 드리움 | c1, c2, c3 |
| **E2-depth-heights** | 가까운 아이(3.5m)와 먼 어른(5.9m)이 화면에서는 비슷한 크기 | c1, c2, c4 |

이 장면들은 color.png만으로는 흔히 예상하는 방향으로 틀리기 쉽게 만들었습니다.
- E1: 위에서 내리쬐는 빛으로 그리기 쉽습니다.
- E2: 두 사람을 나란히 같은 거리에 그리기 쉽습니다.

## 실행

파일 위치는 `docs/review-evidence/2026-11-06-llm-ablation/`입니다.

1. 모델은 **나노바나나(Gemini) 하나**만 씁니다. 모델을 섞으면 비교가 안 됩니다.
2. 장면마다, 조건마다 **새 대화**를 3번 엽니다.
   - 각 대화에서 조건 폴더의 이미지를 모두 첨부하고, `prompt.txt` 내용을 그대로 붙여 넣어 보냅니다.
   - 결과를 장면 폴더의 `results/<조건>-<회차>.png`로 저장합니다. 예: `E1-under-light/results/c3-light-2.png`
3. 다시 생성하거나 고르지 말고 **나온 첫 결과**를 저장합니다.
4. 조건 순서를 섞으면 더 공정합니다. 예: c3 → c1 → c2 → c1 → c3 → c2…

총 2장면 × 3조건 × 3회 = **18장**입니다.

## 채점

- 채점 질문은 장면 폴더의 `questions.md`에 있습니다. 질문마다 정답은 "예" 하나입니다.
- 결과 18장이 `results/` 폴더에 모이면 말씀해 주세요. 제가 이미지를 보고 질문별로 예(1)/아니오(0)를 매겨 조건별 평균과 회차 간 편차를 표로 정리하겠습니다.
- 직접 채점하셔도 됩니다. 장면별로 이렇게 적으면 됩니다.

```
조건-회차 | Q1 Q2 Q3 Q4 Q5 | 합
c1-1      |                 |
...
```

## 판단 기준

| 판단 | 조건 |
|---|---|
| **효과 있음** | 추가 자료 조건(c3 또는 c4)의 3회 평균이 c2보다 1점 이상 높고, 3회 중 최저점도 c2의 최고점 이상 |
| **불확실** | 평균은 높지만 회차끼리 겹침. 회차를 늘려야 함 |
| **효과 없음** | 평균 차이가 0.5점 이하. 그 자료는 빼거나 전달 방식을 바꿔야 함 |

설명 문장 효과(c1 → c2)도 같은 기준으로 봅니다.

- E2: 아이가 더 가까움, 화면 키 비율 0.75~1.33, 아이 발이 화면 아래쪽
