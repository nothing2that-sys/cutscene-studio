# 실제 CLI 생성·수정·재생성 영상

2026-11-12 실제 로컬 편집기와 로그인된 Codex CLI로 녹화했습니다. 새 API 키는 만들지 않았습니다.

[영상 재생](cutscene-ai-cycle.mp4) · [수정 전 결과](result-1.png) · [수정 후 결과](result-2.png)

- 소설과 인물 설정 입력 → 한 번에 이미지까지 생성.
- 같은 장면에서 화풍·카메라 위치·화각 수정.
- 현재 구도로 이어서 생성 → 수정 전/후 결과 비교.
- 실제 호출: 장면 구성 1회, 이미지 생성 2회. 모의 응답이나 이전 생성 결과로 대체하지 않았습니다.
- 대기 구간은 실제 소요 시간과 배속을 표시해 축약했습니다. 상단 설명과 결과 확대는 녹화용 주석입니다.
- 84초, 1920×1080, 30 fps, H.264 MP4. 음성 없이 한국어 자막으로 설명합니다.

## 타임라인

```text
00:00 소설 입력부터 작화까지, 앱 안에서 한 사이클
00:05 01  소설과 인물 설정을 입력합니다
00:14 02  “한 번에 이미지까지”를 누릅니다
00:17 03  소설에서 3D 장면을 자동 구성
00:22 04  현재 장면의 참조를 보내 최종 이미지 생성
00:28 05  첫 번째 이미지가 앱으로 돌아왔습니다
00:37 06  결과를 보고 화풍과 구도를 수정합니다
00:46 07  화면을 돌려 새 구도를 잡습니다
00:54 08  수정한 현재 구도로 이어서 생성
00:59 09  수정한 참조로 두 번째 이미지 생성
01:05 10  수정된 구도의 이미지까지 완성
01:14 한 장면, 구도 수정 전과 후
```

실행·검증 근거는 recording-report.json과 edit-report.json에 있습니다. 구도·포즈 보존 정도는 생성 모델에 따라 달라질 수 있습니다.
