# 다관절 인형 중심 부품 시제품 02

후속 개선판: [시제품 03 — 조형 보완과 경량화](DOLL_CORE_REFINEMENT.md). 아래 수치와 이미지는 시제품 02 기록이다.

2026-11-03. 부위별 제작의 첫 단계인 **흉곽·가슴 / 복부·허리 / 골반·고관절**을 새로 조형했다. 이전 메시를 잘라 색만 바꾼 구조 분석 화면과 별개다. 외형 검토용이며, 완성된 전신 인체나 관절 검증 통과 결과는 아니다.

실행 화면: http://127.0.0.1:3001/doll-core.html

## 실제 구현

`app/src/doll-core-geometry.js`의 새로운 부품 설계 데이터를 사용한다. 이전 `body-study-cage.js`의 몸통 단면과 메시를 가져오지 않았다. 각 부품의 독립적인 단면별 반폭·앞/뒤 깊이, 가슴의 넓은 부착부와 위아래 비대칭 볼륨, 쇄골·흉골·등의 기복을 가진 입체 부피를 정의했다. 그 부피에서 소켓을 차감하고 표면을 추출하므로, 소켓 안쪽 벽과 입구가 실제 메시로 존재한다. 관절 원을 이미지로 그려 넣은 것이 아니다.

표면 추출은 앱에 이미 포함된 Three.js의 MarchingCubes를 사용한다. 표면 정점 용접, 퇴화 삼각형 정리, 짧은 평활화, 부피장의 기울기에 따른 법선을 적용한다. 새 패키지 설치, 이미지 생성 또는 원본 첨부 수정은 하지 않았다. 기본 추출 해상도는 부품당 64³이며, 조형 JSON의 `resolution`은 64/72/80을 지원한다. 이 수치는 인체 치수나 제조 정밀도가 아니다.

| 부품 | 이번 조형 | 연결부 |
|---|---|---|
| 흉곽·가슴 | 쇄골 밑에서 가슴으로 이어지는 넓은 표면, 가슴 아랫면, 후면의 약한 견갑부 기복 | 좌우 어깨 소켓, 아래쪽 복부 수용부 |
| 복부·허리 | 갈비뼈 아래에서 좁아지고 장골 쪽으로 퍼지는 외피, 약한 배꼽/중심 방향 | 흉곽 아래와 골반 위에 들어가는 둥근 상하 끝단 |
| 골반·고관절 | 장골 폭, 앞면의 서혜부 아치와 중앙부, 후면 볼륨 | 위쪽 허리 수용부, 좌우 고관절의 실제 공동 |

어깨·고관절의 시험 구관절 표시를 켜면 수용부와 구의 위치를 확인할 수 있다. 이 구는 팔·다리 외피나 완성된 관절 기구를 뜻하지 않는다. 소켓과 1px 작은 시험 구의 크기 관계는 디지털 시제품의 가정이며 제조 공차가 아니다.

세 부품은 별도 강체로 계층 조립한다. 골반 → 하부 허리 중심 → 복부 → 상부 허리 중심 → 흉곽 순이다. 부품 분해, 개별 부품 보기, 중립/원본 비교용 기울임/굽힘/비틀기와 상부 허리 시험 회전을 제공한다. 회전할 때 부품 메시를 다시 생성하거나 늘이지 않는다.

## 조형 편집과 파일

화면 오른쪽에서 조형할 부품을 고르고 단면별 반폭·앞·뒤 깊이를 수정한다. 가슴 돌출도 조절할 수 있다. 변경할 때만 해당 메시를 다시 생성한다. JSON 저장/열기와 초기화, 실제 표시 메시의 OBJ 내보내기를 제공한다. 조형 JSON에는 단면·소켓 중심과 반경·볼륨 제어값이 들어 있다. 기존 앱의 포즈 JSON과 다른 형식이다.

OBJ에는 현재 세 부품의 조립 변환이 적용된다. 화면에서 한 부품만 보고 있더라도 세 부품을 모두 내보낸다. 시험 구관절은 내보내지 않는다. JSON을 저장하지 않고 페이지를 닫으면 조형 수정이 유지되지 않는다.

## 원본 비교 조건

몸통 확대는 원본의 x=300…660, y=190…670 영역에 대응하는 고정 정사영 프레임이다. 개별 부품 선택 때는 자동 확대하며 원본 겹침을 비활성화한다. 원본 겹침은 원본 비교용 기울임 + 중심 조립체 + 정면 + 분해/추가 회전 0에서만 제공한다.

원본 비교 자세는 골반의 기울임, 복부의 기울임, 흉곽의 기울임/회전으로 구성한 강체 조립 프리셋이다. 원본에 맞추기 위해 부품을 휘거나 단면을 변형하지 않았다. 어깨 관절 중심을 먼저 맞췄으며, [reference-anchors.json](review-evidence/2026-11-03-doll-core/reference-anchors.json)에 원본 수동 판독 좌표와 실제 투영 좌표를 기록한다. 고관절 중심은 원본에서 가려진 위치의 추정이다. 관절 중심 보정은 외곽 일치 점수가 아니다.

한 장의 선화이므로 정확한 카메라, 깊이, 후면, 내부 소켓과 축을 복원했다고 주장하지 않는다. 원본 겹침에서 가슴의 오른쪽 외곽, 복부 중심선, 골반의 위치/기울기에 차이가 남는다. 이 비교 프리셋을 원본 자세의 완전한 복원으로 취급하지 않는다.

## 직접 렌더 확인 후 수정

초기 추출은 관절 입구와 허리 경계가 톱니처럼 보이고 표면 방향이 불안정했다. 단순히 재료나 조명으로 가리지 않고 추출·정점 연결·경계 평활화와 법선 계산을 수정했다. 메시의 방향 일관성도 검사했다. 이후 개별 부품, 분해 상태, 측면/후면, 원본 겹침을 다시 열어 확인했다.

최종 기본 조립체 외피는 **46,708 삼각형 / 3 draw calls**다. 시험 구관절은 별도다. 마지막 검증 브라우저에서 기본 세 부품 생성은 약 0.8초였으며 유휴 상태의 연속 렌더 루프는 사용하지 않는다. 이는 저사양 PC에서 측정한 FPS나 완성 전신 모델의 성능 보장은 아니다. 전신 제작 뒤 메시 최적화가 더 필요하다.

## 확인한 것과 남은 것

[checks.json](review-evidence/2026-11-03-doll-core/checks.json)은 다음 기술적 확인 결과다. 외형 합격 판정에 사용하지 않는다.

- 실제 브라우저 렌더와 각 부품의 다면 캡처.
- 부품별 열린 경계 0, 비다양체 모서리 0, 뒤집힌 연결 방향 0, 유효한 유한 정점과 양의 부피.
- 소켓이 없을 때 부품 내부인 지점이 소켓 차감 후 외부가 되는 것. 실제 공동 생성 확인.
- 굽힘/비틀기 때 부품의 로컬 메시 정점이 변하지 않는 것.
- 조형 변경에 따른 실제 정점 변화, JSON 저장/재열기 후 같은 메시 복원, 초기화.

**형태와 조립에서 남은 차이:**

- 가슴 위/아랫면과 쇄골의 전환이 아직 단순하며 원본의 비대칭 실루엣을 충분히 재현하지 못했다.
- 목과 팔 외피가 없는 중심 부품 단계이므로 어깨 소켓 주변의 실제 삼각근/겨드랑이 연결은 미완성이다.
- 골반은 기존의 수평 자락에서 실제 고관절 구멍을 가진 형상으로 바뀌었지만, 서혜부 중앙과 후면 볼륨은 추가 조형이 필요하다.
- 추출된 입구/경계는 확대하면 약간의 요철이 남는다. 최종 조형용 토폴로지 정리 전이다.
- 허리 회전에서 외피 간섭이 남는다. [interface-samples.json](review-evidence/2026-11-03-doll-core/interface-samples.json)에 표면 정점의 일부를 상대 부품의 부피장에 대조한 진단을 기록했다. 원본 프리셋에서는 복부/골반 사이에도 간섭이 있다. 부피장 수치는 정확한 최단 거리나 제조 공차가 아니다. 자동 충돌 보정, 허용 가동범위 확정, 소켓 입구의 동작 여유 조형은 완료하지 않았다.
- 새 팔·다리·목·손발 외피와 기존 리그 연결은 진행하지 않았다. 다음 제작은 허리 경계와 관절 여유 보완, 이어서 한쪽 어깨–상완–팔꿈치–전완이다.

이번 결과는 **중심 부품의 실제 조형 및 조립 검토 시제품**이다. 전신 외형 완성이나 모든 관절 동작 검증 완료로 보고하지 않는다. 기존 앱 기본 인체, 고정 뼈 길이, 관절 제한, 포즈/JSON, Undo/Redo, 캡처·전달 묶음 코드는 변경하지 않았다. 해당 기능의 전체 회귀 검사를 이번 작업에서 다시 실행한 것은 아니다. 사용자 외형 확인 전 기본 모델 교체는 하지 않는다.
