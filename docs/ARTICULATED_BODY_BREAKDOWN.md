# 원본을 다관절 작화 인형으로 읽기

2026-11-03. 사용자 요청: 원본을 부위별로 분석하고 다관절 인형을 기준으로 제작한다.

## 방향 수정

이 원본은 해부학적 외형을 단순화한 다관절 작화 인형으로 해석하는 것이 적절하다. 원형 연결부가 드러나면서 몸통과 팔다리의 윤곽은 인체처럼 이어지는 것이 목표다. 앞선 시제품에서 팔꿈치·무릎을 하나의 매끈한 표면으로 연결한 변경은 이 목표와 맞지 않는다. 그렇다고 구와 원통을 나열하는 기존 방식으로 되돌아가지는 않는다. **부품마다 조형한 외피 + 회전하는 연결부 + 방향을 읽는 보조선**을 함께 설계한다.

그림에서 읽은 외형과 실제 가동 구조의 제안은 구분한다. 한 장의 그림만으로 소켓 내부, 관절 축 방향, 후면, 정확한 깊이까지 알 수는 없다. 실제 제품의 구동 기구나 제조 공차를 복원하는 작업도 아니다. 앱 안에서 움직일 작화용 디지털 인형의 설계다.

## 부위별 분석과 조형 기준

| 부위 | 원본에서 읽는 형태 | 제작할 부품·연결 제안 | 피할 오류 |
|---|---|---|---|
| 머리 | 위는 넓고 턱으로 갈수록 좁은 달걀형. 기울어진 얼굴 중심선과 눈높이선 | 머리 외피 1개, 머리 아래 목 연결. 보조선은 표면에 표시 | 완전한 구, 둥글게 뭉친 턱 |
| 목·쇄골 | 목 아래가 양옆 쇄골로 퍼진다. 쇄골은 어깨까지 연결되어 읽힌다 | 목 외피와 흉곽 상단을 함께 맞춘다. 머리 회전 중심과 목 밑 연결을 별도로 둔다 | 목 원통을 흉곽 위에 꽂기 |
| 흉곽·가슴 | 쇄골 아래 넓은 면에서 가슴 볼륨이 내려오며, 바깥 곡선과 아랫면이 구분된다 | 흉곽 외피 1개 안에 좌우 가슴을 조형. 어깨 소켓과 겨드랑이의 앞뒤 면 포함 | 공 두 개를 별도 부품처럼 붙이기 |
| 어깨·상완 | 어깨에는 원형 영역이 드러나며 상완으로 테이퍼된다 | 상완 외피의 근위부에 삼각근 덮개, 흉곽 측에 소켓. 둘이 회전하면서 윤곽을 잇도록 설계 | 작은 볼에 캡슐을 꽂거나 어깨가 몸통에서 떨어짐 |
| 팔꿈치 | 원형 회전부와 구부러진 상완/전완의 끝이 읽힌다 | 제안: 굽힘축을 가진 회전부와 양쪽 외피 끝의 여유 공간. 구조를 본 뒤 이중 관절 필요 여부 결정 | 무조건 연속 피부로 메우기, 관절 위에 덮개 붙이기 |
| 전완 | 팔꿈치 쪽이 넓고 손목으로 얇아짐. 한쪽 외곽과 반대쪽의 곡률이 다름 | 좌우로 대칭인 원통 대신 단면 중심이 이동하는 외피. 손바닥 방향을 바꾸는 회전도 분리해서 계획 | 균일한 캡슐과 둥근 손목 끝 |
| 손목·손 | 작은 손목에서 납작한 손바닥으로 퍼지며 엄지가 옆으로 분기 | 손바닥 외피, 엄지, 나머지 손가락의 마디를 구분. 손목 회전 중심을 손바닥과 접속 | 손목 단차, 튜브를 펼친 손, 포즈와 무관한 손바닥 방향 |
| 복부·허리 | 늑골 아래에서 좁아져 장골로 다시 넓어짐. 중심선이 비틀림을 보여줌 | 제안: 흉곽–복부–골반의 3부품. 맞물리는 가장자리로 굽힘/기울임/비틀기를 수용 | 움직일 때 외곽이 끊기는 공 연결, 얇은 허리봉 |
| 골반·고관절 | 좌우 장골, 아래로 모이는 앞면, 서혜부 사선, 두 허벅지의 넓은 뿌리 | 골반 외피에 좌우 고관절 소켓. 허벅지 상단의 둥근 관절 부분을 받아들이는 형태 | 큰 타원체 골반, 수평 치마 자락 같은 경계 |
| 허벅지 | 상단이 넓고 무릎으로 좁아짐. 안쪽·바깥쪽 볼륨의 높이가 다름 | 고관절에서 무릎까지 하나의 외피. 근위부 구관절과 무릎 측 끝단을 같이 조형 | 가로 보조선 위치에서 잘라 새 관절 만들기 |
| 무릎 | 앞쪽 원형/타원형 회전부, 옆의 작은 연결 영역, 위아래 끝단이 보임 | 제안: 굽힘축과 측면 연결부를 가진 관절. 무릎 앞면은 회전부 형상 안에 포함 | 피부 위에 별도 무릎 뚜껑 붙이기 |
| 종아리 | 위쪽 볼륨에서 발목으로 길게 좁아짐. 정강이 앞면과 뒤쪽 볼륨이 다름 | 비대칭 외피와 얇은 발목 접속. 앞·옆·뒤 단면을 각각 조형 | 아래까지 비슷한 굵기, 안팎이 같은 곡선 |
| 발목·발 | 작은 발목, 발꿈치 돌출, 발등 경사, 넓은 앞꿈치와 발가락 | 발 외피를 앞뒤로 길게 둔 쐐기로 먼저 조형한 뒤 발가락. 발목 중심과 발꿈치 위치를 함께 맞춤 | 정면 그림만 아래로 늘린 부츠 형태 |

## 선을 모두 부품 경계로 자르면 안 되는 이유

- 머리의 세로/가로선, 몸통 중심선: 표면 방향을 읽는 보조선.
- 허벅지·종아리 중간 가로선: 형태를 읽는 단면 보조선으로 해석. 원본에서 회전 관절이라는 근거가 없다.
- 어깨·팔꿈치·손목·무릎·발목의 원/타원: 관절 연결부 외형을 설계하는 기준. 원이 보인다고 모두 같은 구관절로 확정하지 않는다.
- 복부 아래와 서혜부의 선: 외피 경계와 조형 방향의 후보. 정확한 내부 구조는 별도 설계한다.

## 현재 확인 화면

`http://127.0.0.1:3001/body-part-study.html`

원본 위 부위를 누르거나 목록에서 선택하면 해당 부품을 강조한다. 선택 부품만 보기, 부품 분해 간격, 정면·측면·후면·사선, 마우스 회전을 제공한다. 손가락/발가락은 해당 손/발과 함께 분해된다. 검은 작은 점은 회전 중심 제안 위치이며 실제 관절 표면은 아니다.

**이 화면의 3D 부품은 기존 시제품 외피를 분할한 구조 분석용이다. 새로운 부품 조형과 관절 기구를 완성했다고 볼 수 없다.** 앞선 메시의 골반과 발 문제도 그대로 보이며, 분할만으로 해결되었다고 주장하지 않는다. 원본 좌우는 화면 기준이고 3D는 중립 자세이므로 둘을 같은 포즈의 실루엣 비교로 해석하지 않는다. 같은 포즈 비교는 기존 `body-study.html`에서 한다.

## 실제 제작 순서

1. **중심 조립체: 흉곽·가슴 / 복부 / 골반.** 세 부품을 정면·측면·후면에서 각각 조형한다. 원본 포즈의 외곽과 함께 확인하되, 숨은 깊이는 가정으로 기록한다. 골반부터 허벅지 소켓 입구를 만든다.
2. **한쪽 어깨–상완–팔꿈치–전완.** 부품 하나의 외형과 관절부 외형을 함께 만든다. 중립과 팔 올림 상태에서 어깨가 탈락하지 않고 팔꿈치 회전부가 원본처럼 읽히는지 확인한다. 반대쪽은 그 후 전개한다.
3. **한쪽 고관절–허벅지–무릎–종아리.** 고관절 소켓과 무릎 연결을 먼저 맞추고 중립·벌림·굽힘을 비교한다. 뼈 길이는 그대로 두고 외피의 부착 위치를 조정한다.
4. **손발.** 손바닥과 발의 실제 입체 형태부터 만들고 손가락/발가락을 조형한다. 몸체와 접속 단면을 맞춘다.
5. **조립 후 같은 포즈 비교.** 부품 외형과 조립 시 실루엣을 별도로 확인한다. 원본의 원형 관절이 보이는 느낌까지 비교한다. 외형 확인 전 앱 기본 모델은 교체하지 않는다.

각 단계의 산출물은 부품 정면/측면/후면과 조립 상태다. 전체 모델을 한 번에 다시 생성한 뒤 비슷해졌다고 결론내리지 않는다. 기존 리그의 고정 길이, 관절 제한, 포즈 저장, Undo/Redo 및 캡처 기능은 보존한다.

## 중심 부품 조형 진행

별도 설계 데이터로 흉곽·복부·골반과 실제 소켓을 새로 조형하고 조립한 `doll-core.html`을 추가했다. 이전 부품 분석 화면은 기존 메시의 구조 분석으로 남긴다. 부품별 다면 렌더, 조형 JSON/OBJ 및 간섭을 포함한 남은 차이는 [DOLL_CORE_PROTOTYPE.md](DOLL_CORE_PROTOTYPE.md)에 기록했다. 전신과 관절 가동의 완성 판정은 아니다.
