# 필요할 때만 쓰는 포즈 참고

기본 작업은 중립 3D 마네킹의 관절·IK와 사용자 수정이다. 이미 적합한 참조가 있으면 재검색하지 않는다. 기존 단계의 포즈 이미지 생성이나 융합을 필수 절차로 만들지 않는다.

## 검색 요청

사용자가 포즈 참조 검색을 요청했을 때만 번들 gallery.py를 사용한다. 포즈 이미지 검색 출처는 https://ai-pose-gallery.pages.dev/ 내부다. 사용 시 최신 이용 안내를 확인하고 [보존한 출처 안내](gallery-terms.md)의 범위를 적용한다. 일반적인 자세 설명·사용자 제공 이미지는 이 갤러리 자료와 구분한다.

python "<스킬>/scripts/gallery.py" search "앉아서 한손으로 턱을 받친 자세" --limit 5

선택 후보의 미리보기와 원본을 한 장씩 가져와 실제로 연 뒤 지지점·앉기/서기·몸통 기울기·팔꿈치/손·무릎/발·접촉·인원·카메라 높이·인물 좌우를 비교한다. 검색 태그와 일치 점수는 시각 검증이 아니다. 필요한 옵션은 gallery.py --help와 search --help로 확인한다. 전체 인덱스를 문맥에 넣거나 이미지를 일괄 취득하지 않는다.

가까운 후보 1~3개의 선택 이유·차이·출처와 실제 로컬 파일을 제공한다. 없으면 이 갤러리 안에서 핵심 특징으로 한 번 넓혀 보고, 없다는 사실을 구분해 일반 자세 설명이나 사용자 제공 참조로 이어간다. 준비한 URL/ID를 실제 이미지 참조처럼 보고하지 않는다.

## 여러 포즈의 조합

참조마다 base/torso/arms/hands/legs/support/camera 중 필요한 역할만 배정한다. base는 하나로 몸 전체 균형·무게·시점을 정하고 나머지는 해당 부분만 반영한다. 여러 각도는 출력 카메라 하나의 3D 관계로 해석한다. 지지점이나 관절 범위가 충돌하면 기본 자세를 유지하고 보조 특징을 조정한다.

일반적인 ‘포즈를 섞어줘’는 우선 장면 JSON의 관절·지지점 제안으로 처리한다. 앱이 지원하지 않는 정확한 손 접촉·세부 손가락은 수동 조정 범위로 남긴다. 이미지 형태의 융합 참조를 명시적으로 요청하면 확인한 실제 입력 이미지와 역할표로 생성하며, 그때만 imagegen 스킬/도구를 연결한다. 생성한 참조는 synthesized_pose로 기록하고 원본 갤러리 ID를 부여하지 않는다.

한 후보만 쓰면 융합 대신 변형으로 구분한다. 생성 출력의 손발 수·관절 연결·접지·좌우·시점을 실제로 확인한다. 이후 캐릭터 적용에서는 채택된 조합 참조와 정본 외형을 역할별로 전달하고 원본 후보 전체를 다시 섞어 충돌시키지 않는다.
