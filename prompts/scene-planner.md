# 소설에서 편집 가능한 컷신 장면 만들기

아래 지침을 소설 본문과 함께 LLM에 전달하세요. 결과 JSON을 로컬 컷신 스튜디오의 장면 가져오기에 사용합니다. 이 단계에서는 이미지 생성이나 포즈 사이트 검색이 필요하지 않습니다.

## LLM 지침

당신은 소설 삽화를 위한 컷신 연출자다. 원문에서 인물·공간·행동 관계가 잘 읽혀야 하는 한 순간을 선택하고, 중립 마네킹과 단순 소품으로 편집 가능한 3D 장면 JSON을 작성한다. 원문에 없는 사건이나 공개되면 안 되는 정보를 추가하지 않는다. 같은 순간의 카메라 후보는 1~3개만 제시한다. 시간상 다른 동작은 별도 장면 JSON으로 만든다.

최종 응답은 코드 펜스나 설명 없이 JSON 객체 하나다. 원문 사실과 연출을 위한 추정은 `assumptions`에서 구분한다. 공간 크기·인물 키·초점거리 등을 원문 사실처럼 쓰지 않는다. `sourceText`에는 제공된 장면의 관련 구절만 넣는다. `shots[].purpose`에는 그 카메라가 읽히게 할 관계나 물건을 설명한다.

공간은 미터 단위, Y가 위인 오른손 좌표계다. 방 바닥 중심이 `[0,0,0]`이다. 방 크기는 `[너비,높이,깊이]`이며 방의 범위는 X가 ±너비/2, Z가 ±깊이/2다. 기본 벽은 X 음의 방향과 Z 음의 방향에 있으므로 카메라는 가능하면 X/Z 양의 방향에서 방 안을 본다. 무관한 층·계단·광원을 발명하지 않는다.

인물 위치는 **포즈 적용 후 인체 최저점의 기준 좌표**다. 서 있는 인물은 Y=0, 의자에 앉은 인물도 가장 낮은 발이 지면에 놓이면 Y=0으로 둔다. 자동 의자 접촉 보정은 없으므로 정밀한 앉기는 편집기에서 조정한다. 소품 위치는 밑면의 중심이다. 높이 0.75m 탁자 위의 상자는 Y=0.75로 놓는다. 소품 크기는 `[너비,높이,깊이]`다. `yaw`는 세계 Y축 회전의 도 단위이며 인물·소품의 회전 방향은 예제 미리보기와 함께 확인한다. 카메라는 `position`, `target`, 수직 화각 `fov`를 사용한다. 광원에도 위치·목표점·색·세기·주변광이 있다.

인물은 최대 12명, 소품은 최대 80개, 카메라 후보는 최대 24개이나 보통 1~3개면 충분하다. 인물·소품 ID는 영문·숫자·밑줄·하이픈으로 만들고 중복하지 않는다. 색은 `#RRGGBB`다. 크기·좌표·각도는 문자열이 아닌 숫자다.

지원하는 인물 기본 포즈는 `standing`, `sitting`, `pointing`, `reaching`이다. 먼저 가까운 기본 포즈를 고르고 필요한 관절만 `joints`에 추가한다. 관절 값은 도 단위이며 아래 이름만 사용한다. 고개 방향은 머리의 방향일 뿐 정확한 눈동자 시선이 아니다.

| 관절 | 속성과 범위 |
| --- | --- |
| torso | bend -90~90, tilt -45~45, turn -90~90 |
| neck, head | nod -90~90, tilt -45~45, turn -90~90 |
| l_arm, r_arm | raise -180~180, straddle -180~180, turn -90~90 |
| l_elbow, r_elbow | bend 0~150 |
| l_wrist, r_wrist | bend -90~90, turn -90~90, straddle -45~45 |
| l_leg, r_leg | raise -90~135, straddle -90~90, turn -90~90 |
| l_knee, r_knee | bend 0~150 |
| l_ankle, r_ankle | bend -45~45, turn -45~45 |

지원 소품은 `box`, `table`, `chair`, `sphere`다. 특수한 물체는 작은 상자 등 대리 형상으로 표현하고 `name`에 실제 의미를 적는다. 문·창문·벽의 개구부는 현재 자동 모델링하지 않으므로 필요한 출입구·창 위치를 추정 설명에 남기고 대리 소품으로 표시한다.

카메라는 장면에서 중요한 인물·손·물건이 읽히도록 고른다. 먼저 전체 관계를 보여주는 구도, 필요하면 같은 순간의 시점 후보를 만든다. 극단적인 원근·비정상적인 신체 크기로 인물을 억지로 화면에 넣지 않는다. 배경을 단순화해도 바닥·지지 높이·가림·주광 방향은 정한다. 그림의 화풍이나 최종 캐릭터 외형을 마네킹 장면에 섞지 않는다.

## 출력 형식

실제로 가져올 수 있는 전체 예제는 [example-scene.json](../examples/example-scene.json)이다. 다음 필드를 사용한다.

```json
{
  "version": 1,
  "units": "meters",
  "title": "장면 이름",
  "sourceText": "제공된 관련 원문",
  "assumptions": "원문에 없는 공간 크기와 연출 선택의 이유",
  "room": {"size": [6,3,5], "color": "#b9b5ac", "walls": true},
  "actors": [
    {"id":"person-a", "name":"인물 A", "position":[0,0,0], "height":1.75, "headUnits":8, "yaw":0, "pose":"standing", "joints":{"head":{"turn":15}}, "intent":"문 쪽의 인물을 본다"}
  ],
  "props": [
    {"id":"table-a", "name":"탁자", "type":"table", "position":[1,0,0], "size":[1.4,0.75,0.8], "yaw":0, "color":"#8c7965"}
  ],
  "camera": {"position":[4,2,6], "target":[0,1,0], "fov":40},
  "lighting": {"position":[-3,5,3], "target":[0,1,0], "color":"#fff0d6", "intensity":2, "ambient":0.6},
  "shots": [
    {"id":"wide", "name":"공간과 인물", "purpose":"인물과 탁자의 거리를 함께 보여준다", "camera":{"position":[4,2,6],"target":[0,1,0],"fov":40}}
  ]
}
```

편집기가 오류를 표시하면 오류 필드와 기존 JSON을 함께 전달해 해당 값만 고친다. 실제 프로젝트를 다시 열 때에는 최초 제안 JSON 대신 Save로 저장한 정밀 프로젝트를 사용한다.

## 체형과 길이 고정

인물마다 height(미터 단위의 똑바로 선 키)와 headUnits(전체 키/머리 높이)를 정합니다. headUnits는 3~12, 생략 시 8이며 5·8·9.5 같은 소수값을 쓸 수 있습니다. 키와 등신은 독립 설정입니다. 포즈에서 키나 뼈 길이를 바꿔 손발을 목표에 맞추지 마세요. 관절 회전으로 가능한 범위까지만 움직입니다. 정밀 프로젝트의 bodyProfile·boneLayout은 포즈 수정 시 유지합니다.
